# 结构计算复核

仅在选择结构计算复核、综合校审或明确的结构专项时加载。复核已有结果和可追溯算式，不重新求解整体模型；“仅错漏碰缺”的图面一致性检查见 [建结协调](coordination.md)。

## 图算身份与构件对应

核对项目身份、资料日期、软件及版本、结构体系、材料、场地与抗震参数、风雪条件、层高、嵌固端和模型几何。计算目录中的旧项目名可能来自复制，不单凭路径认定错用模型；结合平面、轴网、版本记录和参数建立对应。

匹配键至少包含楼层、轴线/空间位置、构件编号及截面；同名梁、不同楼层重复编号、屋面引用闷顶层、局部变截面不能直接合并。图算几何、材料、保护层、支承宽度或边界不同，先登记矛盾及其影响，再确定哪些比较仍有效；“施工加大”不能自动解除模型矛盾。

## 荷载与结果

按“用途与构造做法 → 材料密度和厚度 → 面荷载/线荷载/集中力 → 作用位置与传力路径 → 永久/可变属性 → 工况与组合”核对。结构自重与附加恒载分开，不能重复计入；总砌体容重不能证明手工墙线载正确。坡屋面风雪、开敞阳台面层、花池、水箱及设备支架分别追踪。

按已有原始输出核对质量、周期、位移、层间位移、轴压比、超限及异常提示，记录输出页或行号和适用依据。整体位移满足不证明每块板、梁柱节点或基础满足；缺少控制工况、局部验算或荷载输入时保留具体缺口。

## 配筋与软件标注

按“图模几何材料一致 → 对应构件与控制截面 → 解释软件符号和单位 → 识别集中标注与有效原位筋 → 比较面积 → 复核构造和正常使用”执行。

- YJK、PKPM/SATWE 分别依据该项目的软件版本、图例、原始结果字段或官方说明解释；不按图形相似迁移规则，也不把输出文件名当作软件身份的唯一证据。
- 保留原串、证据位置、数值和单位。cm²/mm²、每米宽度/整截面、单面/全截面、上下部、方向及箍筋肢数必须一致；柱全截面纵筋、单侧筋和异形柱分肢不能混比，承台单位宽需筋不能直接与每方向总实配比较。
- 需筋图整数显示不是精确值。临界位置取得未取整结果；小数点、钢筋符号或支座归属读不清时重新看图，不能猜读。
- 数值换算和钢筋面积用可核查的本地算式；可以复用 `drawing_review.calculations`，调用前查实际函数签名，无引擎时使用等价已验证计算。每个比较保留输入、单位和算式。
- 截面不同、控制位置不明或原位筋未闭合时，旧需筋与可识别实配只能形成待核线索，不能给出最终配筋通过结论。
- 最小/最大配筋、锚固搭接、节点、裂缝、挠度和承载力分别记录依据与覆盖情况；达到某一配筋率不代替其余验算。

## 基础与完整性

基础、桩及承台核对尺寸、标高、上部定位、地层、持力层、桩长和进入持力层长度。不得用不同钻孔承载力的算术平均替代逐桩条件。承载力、抗震提高、偏心或组合系数必须有可追溯的适用条件；勘察或反力结果缺失时不自行补值。

全量审核应登记全部可识别梁、柱、板、桩、承台、基础和楼梯，并对应计算编号。分别统计“已识别、已映射、已完成比较、待补资料/未完成”，不能用区域阅读率代表逐构件验算率。无法识别总数时写“总量待确认”，不报 100%。

规范依据按本项目的所在地、用途、体系和设计适用日期核实来源及有效版本。`applicabilityVerified` 之类字段只有在项目事实与条文适用条件已经核实后才能置真，不能用模型自述替代核实。历史案例中的最小配筋限值或荷载值不作为新项目默认输入。

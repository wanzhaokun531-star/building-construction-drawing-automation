# 意见、覆盖台账与交付

完成审核或需要交付阶段结果时读取。本约定是工作底稿与报告的最低信息要求，不改变现有审核引擎的 JSON 接口。

## 范围与覆盖台账

记录本次模式、用户选中项、资料版本、逐项或抽查范围及截止状态。台账推荐 CSV（UTF-8，含中文）；需要层级数据时另存 JSON。每行对应检查项及必要的楼层/区域/构件，至少包括：

`检查项编号｜专业｜对象或区域｜是否选中｜状态｜已核数量/总量｜来源版本及页码｜关联问题编号｜缺口或未完成原因`

总量未知时注明待确认；总页数、已读区域数、已映射构件数和已完成比较数分开，不互相替代。未选择项不计入检查分母或资料不足。选中项中的非适用对象说明理由；复审对变化和关联影响另留覆盖记录。

四立面全量核对应另有逐洞口及檐口明细，至少记录：`实例编号｜立面/轴向｜楼层及轴段｜门窗编号/檐口区段｜建筑水平范围及上下缘标高｜对应结构梁柱/梁板编号｜结构水平范围及顶底标高｜基准与差值算式｜建筑/结构图号及PDF页码｜状态｜关联问题编号`。同一弧窗或转角窗跨立面显示时建立交叉索引；各层、各立面数量与物理实例总数应能核对。保留疑点和缺资料的具体字段，不用“已核”二字掩盖尚无法判定的关系。

| 状态 | 使用条件 |
|---|---|
| 已核未见异常 | 指定对象及检查内容已核实，所需证据足够，未发现异常；仅限该范围 |
| 确认问题 | 事实已回到源图/原文核实，包括明确表达矛盾或已核实的缺项；不自动等同规范违规 |
| 疑点 | 有具体迹象，但读数、对应关系或适用条件尚不能支持确定结论 |
| 资料不足 | 缺少所选检查所必需的源图、原始输出或项目条件 |
| 未完成 | 资料存在但未读完、未完成映射、导出/OCR失败、任务中断等 |
| 不适用 | 已核实该检查对当前对象无适用条件，并写出理由 |
| 未选择 | 用户本次范围不含此项；不列作待补资料或错误 |

同一检查项可同时有确认问题和未完成对象。用分行或对象明细保留，不因该项已发现问题而掩盖其余未完成；导出旧引擎格式时保留原始状态/原因，不将它不支持的“未完成”映射为“已核未见异常”。

## 每条意见

使用本项目稳定的问题编号，不以页码或标题代替 ID。记录：

- 状态、问题类别（错/漏/碰/缺或专项）、处理优先级；优先级不能替代结论可信度。
- 图号、PDF 页码（从 1 开始）、楼层、轴线、构件或洞口位置。
- 原始标注及事实、双方证据、统一基准后的比较；缺项附已检索的图纸与引用范围。
- 影响、具体整改建议、需补资料或计算、复核关闭条件；不替设计人员擅定最终参数。
- 涉及规范时记录来源、版本、条号、适用条件；纯图面矛盾可以不引用规范。
- 有计算时记录输入、单位和算式。证据图记录源文件版本、图号、页码、裁图坐标及坐标单位。

候选意见回到原图核验后再进入最终确认问题。被排除的误报及排除原因保留在底稿，避免后续重复提出；严重性不能弥补证据不足。

## 默认成果

1. **一份校审意见 PDF**：范围与版本摘要 → 问题简表 → 逐项详细意见及对应证据 → 所选范围的覆盖与限制摘要。默认包含确认问题、疑点和资料不足，并明确分组；未完成项在覆盖摘要说明。
2. **一份覆盖台账**：保留所有选中项及对象的真实状态，未选专项仅作范围说明，不制造大量无关行。

意见与证据尽量同页；跨页时重复问题编号、定位与必要意见，禁止把全部截图单独堆到报告末尾。证据清晰到可核对原数值，简表与详版使用相同编号、状态和数量。

用户要求“只列不满足项”时，报告的问题简表和详细意见只保留确认问题；疑点、资料不足和未完成保留于台账，不混称不满足。报告仍简短说明本次范围、筛选口径及尚未闭合数量；没有确认问题时写“本次未形成确认问题”，不写全部合格。

只有用户要求合并原图/计算书或打印资料时，才追加按专业或资料类别合并的 PDF，保留目录、书签及来源页码对照。用户要求不同专业单独报告时按其要求拆分。只打开最终合并成果，不逐张打开原图、截图和过程 PDF。

## 交付检查

- 本地数据核对问题编号唯一、证据文件存在、引用页码有效、双方引用可定位，合并后页码仍可追溯。发现丢图不能靠排版工具静默跳过。
- 核对简表、详版、状态统计和台账一致；阶段运行成功不等于审核完成，更不等于问题关闭。
- 核对四立面各层的门窗实例、结构对应及檐口区段没有漏项，重复型号未合并掉实例；报告摘要应列出全量分母与已比较数量，并与逐项明细一致。未完成对象未清零时，不宣称全量核对完成。
- 逐页渲染查看合并 PDF，放大核对关键小字、钢筋符号、图表和跨页意见；检查空白、截断、重叠、缺字及证据错配。若使用旧引擎分别生成简详版，完成筛选、合并、统计及视觉核验后才交付。
- 原资料、完整提取和复核底稿保留本地；技能及对外成果不混入密钥、账户账单或无关客户资料。

## 修改复审

新版本输出到新批次，保留原结果与问题编号。检查源文件哈希和实际变更，复审修改处及其关联的平面、立面、剖面、节点、标高、荷载或构件结果；范围仍以本次选中项为准。设计回复“已改”只作为线索，关闭问题需有新图/计算证据并核对关联矛盾已解除。

问题处置状态（待整改、待复核、已关闭、已撤销）与技术判定分开记录；新问题赋新编号，撤销误报保留原因。不把“已关闭”当作整套图纸合格。

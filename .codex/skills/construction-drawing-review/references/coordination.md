# 建筑结构错漏碰缺

用于“仅错漏碰缺”和“综合校审”。本文件的 C01—C09 是人工覆盖台账编号，不是审核引擎的 `--checks` 参数。选中本模式时逐项建立台账；确实不适用的项目注明原因，不能因为没读到而记为不适用。

## 对应方法

先建立建筑与结构图纸对照：楼层名称及实际标高、轴线及方向、局部详图位置、构件编号和轮廓。同名楼层可能对应不同结构层；旋转、镜像、局部改轴号和同名梁重复出现时，用位置与尺寸共同核对。

对比时记录“原始标注 → 解释依据 → 换算值”，保留 m/mm、建筑/结构标高、相对/绝对标高的区别。只有基准相同后才能做差；不统一假设全楼都有相同面层厚度，不用图签比例直接量取施工尺寸。

## 检查清单

| 编号 | 检查内容 | 应形成的对照 |
|---|---|---|
| C01 资料与说明 | 目录与实图、图号图名、修订日期、总说明及图内说明的用途、层数、体系、材料和参数 | 图面明确矛盾列问题；计算路径中的旧项目名只提示来源待核，不直接认定计算书拿错 |
| C02 轴线与尺寸 | 总尺寸与分尺寸、开间进深、轴号、柱偏心、墙厚、平立剖尺寸及局部变截面 | 对应轴段和实体边界；区分轴线尺寸、净尺寸及完成面尺寸 |
| C03 墙柱与支承 | 承重墙、填充墙、构造柱、框架柱、圈梁、过梁、挑空及基础上部定位 | 建筑位置、结构布置、上下层连续关系；墙体或设备支承表达缺口需查节点，承载力留给专项 |
| C04 标高与降板 | 层高表、板顶、梁顶/底、卫生间露台、门槛、室内外高差 | 明确 H/h 指代和局部降板，再核建筑完成面、结构面及面层预留 |
| C05 梁柱与门窗立面 | 四个立面逐层的全部门窗洞口、窗台洞顶、门窗表、平面立面、过梁、结构梁柱和装饰线脚 | 每个实际洞口建立位置、水平范围、竖向范围及对应梁柱；同编号不同层、不同位置分别核对，不以重点抽查代替全量 |
| C06 楼梯 | 梯段方向、踏步数量与尺寸、层高、平台、到达面、洞口、平台梁和净高 | 平面、剖面、结构梯板平台一一对应；完成面及首末级做法共同核对 |
| C07 屋面与悬挑 | 四个立面的高低屋面、屋脊、檐口、起坡、坡度、老虎窗、天沟、露台、阳台、雨篷及女儿墙 | 分立面、标高区段核对建筑轮廓、结构梁板和节点，记录标高差及洞口上方冲突；不从一张平面图推定空间关系 |
| C08 洞口与设备接口 | 已表达的楼板洞、穿梁墙套管、水箱和设备基础、排水口与梁板 | 双方位置、标高、尺寸及构造接口；未选水电专业时不自动审完整系统、回路或负荷 |
| C09 详图与引用 | 详图索引、通用说明、平面与剖面、构件表、节点做法和图例 | 核查引用真实存在且适用于该部位；单处未注但有效通用说明已覆盖，不判漏项 |

各项既检查跨专业关系，也检查单专业内部矛盾。结构说明中两个荷载值或同构件配筋标注不一致，可以作为表达问题记录；不据此推断实际模型输入或配筋是否足够。

## 梁与门窗、立面的专项核对

默认执行四个立面的全量对应。先按图名或轴向确认各立面朝向，并用平面、立面、门窗表交叉清点每层外部门窗；内部门窗与立面洞口分开计数。给每个实际洞口一个实例编号；同型号多樘逐樘列入，弧窗或转角窗在多个立面出现时保留一个物理实例并交叉索引，避免重复计数或遗漏。退台、阳台内侧、局部错层和楼梯半层窗按其实际所在墙面、标高核对，不能一律套本层楼面。

按楼层、轴段和洞口编号记录建筑洞口上下缘、梁柱轮廓、过梁位置及证据。梁底只有在已确认梁顶和截面高度时才按“梁底＝梁顶－梁高”推算；反梁、变截面、局部抬高和装饰包覆分别读取对应详图。

先确认洞口与梁柱在平面位置、墙厚方向上实际重叠，再比较竖向区间。仅立面投影相交或梁底等于洞顶，不能自动判定压洞；洞口是结构洞口、安装净口还是装修完成尺寸必须明确。已确认实体侵入洞口时列碰撞；尚缺剖面、定位或标高时列疑点或资料不足。

引用门窗表前确认编号、楼层、左右朝向和重复实例。连续同尺寸洞口可以复用判读规则，但台账仍列实例覆盖，不能以一个洞口代替不同梁高或窗台条件的所有洞口。

每个立面还应分高、低屋面及转折段核对檐口：对应建筑屋面平面、立剖面、檐口详图和结构屋面梁板、节点，列出屋脊/起坡/檐口/沟底原始标高及其基准，核算尺寸链，检查坡梁、边梁、檐沟和线脚是否侵入下方门窗。结构面、完成面及装饰边界未说明时，不把二者标高差直接当碰撞，也不能默认差值就是面层厚度。

完成判据是四个立面每层的洞口和全部檐口区段都在台账中有明确对应、比较过程与状态。分别汇总“清点总数、已映射数、已比较数、确认问题、疑点、资料不足、未完成”；资料不足和疑点可表示已查完但结论待设计澄清，不能计为无异常。存在未映射或未处理对象时，继续完成可核部分并在交付中列明剩余范围，不能把通读四张立面或完成报告排版称为全量核对完成。

## 漏项与缺图的判定

先检查目录、实际全部相关页面、局部放大、通用说明及引用节点。搜索没有命中、文件名不含关键词、CAD 对象未提取、OCR 空白均不能证明源图没有表达。

- 已核完整相关资料且必要表达确实未提供：记“确认问题”，证据注明已检查的图号和引用范围。
- 因缺关联图、版本不明而无法判断：记“资料不足”。
- 图纸存在但导出、识别或阅读尚未完成：记“未完成”，不写成设计缺陷。
- 只有候选迹象或基准尚不明确：记“疑点”，说明需要补核什么。

确认矛盾时同时展示两处证据，给出需统一的内容，不替设计人员任意选择一侧作为正确方案。整改建议落实到应修改或补充的图纸、表格和节点。

# 追加专业与适用性

用户要求建筑独立专项、消防、给排水、电气或暖通审核时加载。综合校审默认是建结错漏碰缺与结构计算复核的合并，不自动启用本文件全部检查。只读取其他专业图中的设备、洞口或标高接口，不能宣称已完成该专业审核。

- **建筑专项**：总说明、总平、平立剖、门窗、楼梯和构造做法互核；用途、层数、高度、外部场地及规划条件影响适用条文，图中未给条件不能凭项目名称推定。
- **消防**：先明确实际用途及建筑分类，再核耐火、防火间距与分隔、出口、疏散、楼梯及设施。纯自住、出租、经营用途不可互相替代，不因缺少公共建筑设施就判低层住宅违规。
- **给排水**：系统与平面对照管径、标高、设备、流量和排水组织；水箱、设备基础、洞口及穿结构条件与已选结构审核联动。
- **电气**：负荷表、系统图、回路及平面设备对应；导线与保护配置、接地、防雷和等电位分别核对，不能仅凭系统图符号证明实物条件。
- **暖通**：按相关图纸检查系统、设备、管线及适用的防排烟；已选专项却无图时结合用途判断资料不足或不适用，不默认无需设计。

跨专业比较先统一楼层、轴线、标高、位置及尺寸；二维投影相交不必然是实体碰撞。问题保留双方来源，按责任专业标记；同一跨专业问题复用编号，避免重复计数。用户要求各专业单独出意见时按专业导出，每个专业仍合并为最终 PDF，不打开散页。

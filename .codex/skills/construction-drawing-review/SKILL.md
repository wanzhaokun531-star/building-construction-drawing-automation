# 建筑结构施工图校审

将用户选定范围内的问题落实到具体版本、图号、楼层、轴线和证据。默认由 Codex 直接读图判断，复用本地工具提取、计算和排版；不以安装审核引擎或另配模型 API 为前提。仅在用户当前任务明确要求时使用 Cursor，不沿用历史授权。

## 先确定本次范围

用户已明确范围时直接执行，不重复询问。只说“审核这套建筑结构图”“校审本项目”等未限定请求时，先给出以下三个选项；选择前可清点资料，不预先展开技术审核。

| 模式 | 执行内容 | 边界 |
|---|---|---|
| 仅错漏碰缺 | 建筑、结构各自内部一致性及两者之间的轴线、尺寸、标高、构件、洞口、节点和说明协调 | 不自动开展荷载取值、配筋面积、承载力和全面规范专项验算 |
| 结构计算复核 | 已有计算资料的参数、荷载、配筋、基础及相关构造，连同必要的图算对应 | 不自动开展整套建筑专项或求解整体结构模型 |
| 综合校审 | 上述两项合并执行 | 不默认扩大为消防、给排水、电气、暖通的独立审核 |

- “只审错漏碰缺”“只看建结是否打架”直接选择第一项；“复核结构计算书和配筋”选择第二项；“错漏碰缺及计算书都审”选择第三项。用户指定的部分检查项或后续范围调整优先于整套模式。
- “只列不满足项”是报告展示要求，不等于选择了审核范围；范围不清仍先询问。
- 仅错漏碰缺也要核对图面已表达的参数、荷载表和配筋标注是否自相矛盾，但不判断其设计取值或承载力是否满足。未选计算专项不因缺计算书列为资料不足；只有缺少资料确实阻碍所选检查时才登记依赖缺口。
- 从其他专业图纸读取必要接口不等于完成该专业审核。用户要求增加专业或专项时，再加载相应参考。
- 把模式、选中检查项、资料版本、逐项检查或抽查范围写入本次台账。用户要求全量时不能用抽查代替。
- 乡墅及低层住宅的建结错漏碰缺校审，默认将四个建筑立面与结构逐层、逐门窗全部核对，重点检查梁柱与门窗洞口、屋面檐口的冲突和标高差异。除非用户明确缩小范围，不以首层、大洞口或代表性实例抽查代替全量；具体对应及完成判据见[建结协调清单](references/coordination.md)。

## 执行流程

1. **固定版本和资料索引。** 清点已保存文件，记录 SHA-256、文件名、专业、图号/图名、PDF 页码、楼层和日期；从资料确定所在地、用途、层数和结构体系，不凭项目名称补齐条件。DWG 在副本上处理，按 [CAD/PDF 准备](references/cad-pdf.md) 出图；不能把导出失败当作缺图。
2. **先总览，再局部读取。** 原生文字和矢量优先，扫描页或乱码区域按需 OCR。总览平立剖及关键关联图，局部证据保留定位上下文。钢筋专用字体、旋转页面、原位标注和低可信度读数回到图面核实；没有视觉能力的环境只完成可核实的文字部分，其余保留未完成。
3. **按所选模式检查。** 错漏碰缺执行 [建结协调清单](references/coordination.md)；计算专项执行 [结构复核](references/structure.md)；增加其他专业时读 [专业检查](references/disciplines.md)。先对应楼层、轴线、构件、截面、方向、单位及标高基准，再比较。需要排除典型误判时读 [案例与复核场景](references/cases.md)。
4. **形成可核实意见。** 每条记录事实、双方来源或已检索范围、影响、整改建议和关闭条件。确认图面矛盾不等于确认哪张图正确，也不等于承载力不足。涉及规范结论时核实来源、版本、条号及项目适用条件；条件不足只列疑点，不编造强条违规。
5. **核对覆盖和状态。** 区分“已核未见异常、确认问题、疑点、资料不足、未完成、不适用、未选择”。已读页数不代表逐构件校核完成；响应缺失、识别失败、未映射构件和未处理区域不能记为通过。覆盖台账与意见按 [交付约定](references/delivery.md) 整理。
6. **交付和复审。** 默认交付“简表＋详细意见及证据”的一份合并 PDF，另存覆盖台账，只打开最终合并成果。逐页检查排版、证据清晰度和页码。复审保持问题编号，比较新旧版本，复核修改位置及其关联图纸；设计回复本身不构成问题关闭。

## 工具与上下文

现有 `drawing-review` 引擎可选；使用前读 [运行说明](references/runtime.md)，核实已安装版本和命令。三个审核模式是本 Skill 的工作范围，不是假定已有的 CLI 参数；旧引擎省略 `--checks` 可能全选，不可直接用于“仅错漏碰缺”。

提取、数量清点、单位换算、钢筋面积及排版交给已验证的本地工具。先读索引与检查摘要，再取必要局部图和条文，不反复读取整套图纸、完整源码或整本规范。缓存只有在来源、提取器和判断条件一致时复用；改变范围、图纸或规则后重审受影响项。不能靠少检查、丢弃疑点或删去未完成项制造节省效果。

本技能复核已有表达与计算结果，不签发施工图审查合格或整栋结构安全结论；最小配筋满足不能替代承载力、裂缝、挠度、锚固和节点验算。历史案例用于提示检查方法，不作为新项目的事实或规范依据。

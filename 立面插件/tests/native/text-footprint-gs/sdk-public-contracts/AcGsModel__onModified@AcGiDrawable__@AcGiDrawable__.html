AcGsModel::onModified
C++
virtual void onModified(
    AcGiDrawable * pModified, 
    AcGiDrawable * pParent
) = 0;
Parameters
Parameters 
Description 
pModified 
AcGiDrawable that has been modified 
pParent 
Optional AcGiDrawable parent 
Description

This notification informs the Graphic System (GS) that the database representation of the specified AcGiDrawable has been modified. For maximum efficiency, this should be called only when the geometry, attributes, or child list of the AcGiDrawable is modified. 

The parent information is not required and can be set to NULL. If provided, the GS will make the appropriate changes to the parent drawable's cache to reflect the changed status. This allows for partial cache updates of container drawables. In order for this to be effective, however, the GS client must also take care to avoid notifying the parent directly of the same change. The notification function is overloaded for persistent drawables in order to allow the corresponding GS action to be deferred until the next display update. This is to minimize the potential for situations where the client already has a lock on the parent. If a lock conflict does occur, any notification the GS cannot act on is queued and reprocessed on the following update.

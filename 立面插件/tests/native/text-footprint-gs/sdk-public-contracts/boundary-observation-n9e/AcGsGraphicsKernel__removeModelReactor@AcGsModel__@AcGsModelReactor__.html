AcGsGraphicsKernel::removeModelReactor Method   
C++
virtual void removeModelReactor(
    AcGsModel * pModel, 
    AcGsModelReactor * pReactor
) = 0;
Parameters
Parameters 
Description 
pModel 
Input pointer to AcGsModel, which receives notifications. 
pReactor 
Input AcGsModelReactor object to remove. 
Description

This function erases an AcGsModelReactor object from GS.

Remarks

If input AcGsModel value is not null, then the input AcGsModelReactor sends notifications about that particular AcGsModel. If input AcGsModel value is null, then the input AcGsModelReactor sends notifications about all AcGsModel.

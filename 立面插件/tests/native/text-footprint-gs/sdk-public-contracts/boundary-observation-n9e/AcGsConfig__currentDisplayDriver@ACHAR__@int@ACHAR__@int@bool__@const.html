AcGsConfig::currentDisplayDriver
C++
virtual void currentDisplayDriver(
    ACHAR * pszPath, 
    int nPathStrLen, 
    ACHAR * pszDriver, 
    int nDriverStrLen, 
    bool & bAccelerated
) const = 0;
Parameters
Parameters 
Description 
pszPath 
Path of the current display driver 
nPathStrLen 
Size of the buffer allocated for pszPath, in bytes; should be the same as the maximum size allowed for a file path name for the system 
pszDriver 
Name of the current display driver 
nDriverStrLen 
Size of the buffer allocated for pszDriver buffer, in bytes; should be the same size as the maximum file name length allowed for the system 
bHardwareAccelerated 
Output a Boolean that is true if the display driver is capable of hardware acceleration and false otherwise 
Description

This function queries the configuration settings for the current display driver. It reports the path name of the current display driver, the name of the current display driver, and whether the driver is capable of hardware acceleration.

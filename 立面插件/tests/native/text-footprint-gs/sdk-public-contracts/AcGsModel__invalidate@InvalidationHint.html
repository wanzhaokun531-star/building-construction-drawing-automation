AcGsModel::invalidate
C++
virtual void invalidate(
    InvalidationHint hint
) = 0;
Parameters
Parameters 
Description 
hint 
Input hint about the invalidation required 
Description

This method invalidates a given AcGsModel, allowing it to invalidate and rebuild its cache. 

AcGsModel::InvalidationHint is an enumerated type and has three possible values: kInvalidateIsolines, which is a hint to the AcGsModel that any isolines that it might have cached are now invalid, kInvalidateViewportCache, which instructs the AcGsModel to invalidate all per-view caches, and kInvalidateAll, which is a hint that informs the AcGsModel that its entire cache is invalid.

# NativeGsTextFootprint (N9c)

Development-only AutoCAD 2020 / R23.1 x64 ARX. `BCE_TEST_RUN` records entry command/document state and registers one real idle hook; it creates no GS objects or native terminal evidence. Only actual CMDACTIVE=0, empty CMDNAMES, quiescent state and inputPending=0 under the pinned host/thread/document/database identities permit one queued modal `BCE_GS_CAPTURE`. Capture records its own state, requires no SCRIPT bit/extra input, removes the hook and then runs the unchanged v16 GS body synchronously: one owned in-memory database, persistent point control and k3DDrawing kernel/model/offscreen device/view. The owned view uses an explicit custom value style and orthographic XY camera: invisible faces, drawable-color edges without edge modifiers, opaque, no lighting/transparency, fixed width/display mask. Sixteen requested/read-back trait values and operations are retained; active properties require exact equality. Face lighting quality/color/opacity are marked inapplicable only when both sides explicitly use kInvisible/kSet (SDK: faces are not drawn). Kernel createView/device.add pairs with eraseAll/device.erase/kernel.deleteView, including a just-attached-before-style/camera exception regression. The kernel request follows the local 2020 SDK ARXDBG sample. There is one fixed request and no fallback loop. No working/current database switch, GUI view, DWG save, shared GS/profile modification, Plot, Python, or external converter occurs in the native command.

The candidate uses `createAutoCADModel` and `kernel.associate(ownedDb, model, kMain)`; the association is only an attempted route. The device uses this same kernel's `createOffScreenDevice/deleteDevice` pair. It records its actual kernel and original/default renderer without calling a renderer setter. It never edits shared GS/hardware configuration or tries fallback renderer values. The sole scene graph root is the owned modelspace AcDbBlockTableRecord containing only the exact point marker; only that marker is overruled. Every genuine WorldDraw independently records and checks its context database, entity database/ObjectId and model binding before drawing. An actual mismatch fails and is preserved in `gs-trace.jsonl`; it does not establish impossibility of other public routes. The finite custom value style is copied into an AcDbVisualStyle in this same owned database's style dictionary, closed/reopened and copied back with strict equality of all sixteen raw values/operations. The owned BTR/model is added before setting the owned style ObjectId, as the 2020 ObjectId-overload contract requires. ObjectId/database and reopened persistent source are checked initially and after every frame's erase/readd. A false value-getter return is observation unavailable (actual values/operations are null), not a contradictory default output or a requirement that this other overload resolve the ID; it makes no renderer-consistency claim. A true value-getter observation must meet the active contract. A real contradiction permits only the explicit unqualified lifecycle2 nontext diagnostic and then failure, without the five-text matrix. Bounded applicability/attribute flags/viewportDraw observations preserve base behavior, and visible/valid/device/model/viewport state is read without show, flag changes or suppression/global settings. No A/B/C retry is retained: v10 actual evidence excluded that timing hypothesis.

Five N9a controls use independently loaded simplex.shx / gbcbig.shx, height 7 and width factor .75. Each control gets a complete, separate 1024x768 and 2048x1536 RGB snapshot with the same 150x112.5 model field. Control-paper conversion is explicitly 150x112.5 mm, 1:1; dpiX/Y are this conversion, not printer specifications. Frame/phase/font/source identity binds each observation. No Layout translation invariance or glyph-complete claim.

Before text, five colored nontext squares at asymmetric, noncollinear positions verify worldToDevice, ATIL upper-left row order, RGB channel conversion and pixel phase. The first three points select only y orientation and {0,.5} center conventions; the other two positions are held out and independently checked. Both groups have a fixed .55 pixel center residual bound. No text fit. All calibration attempts and the selected mapping are written. Unknown mappings fail.

Native links an exact frozen copy of the existing `src/TextOccupancy.cpp` (SHA256 28D106F22219C8CCD6C0FBC9A6C16EC48296177F6DD0A3D1252C3D9ECF5F3520); no algorithm clone or alternate implementation. Files are frozen by `tools/build_text_footprint_gs.ps1` into the build receipt; the receipt is compatible with unchanged native_case_host.py and watch_native_case.py. Run case `NativeGsTextFootprint`; no capture helper or document OPEN needed. Only the independent controller starts/controls CAD.

Outputs: native-case.json, gs-trace.jsonl, gs-result.json, fonts.json; calibration-W.json/.rgb and five ID-W.json/.rgb for each width. Tight RGB is top-to-bottom, three bytes/pixel. The offline verifier checks every nonwhite full cell against the C++ quadrilateral and exact frame mapping, and has shrink/missing-map/wrong-map negative controls. It never supplies buffers to the native command.

Cleanup removes scene/overrule, closes own point, destroys view, restores only its own database association, destroys model/device, releases kernel, then deletes the owned database. An overrule-removal error retains live state and rejects module unload. Ambient write notifications and current/active/working identities are recorded separately. All work remains developer evidence, no production build eligibility.

Only if the original main BTR hits the specific zero-WorldDraw failure, has no text frames/callbacks and has fully cleaned up with ambient protection intact, one independent diagnostic Session reuses the same default device/model/view/camera/1024/style configuration with a nonpersistent PrimitiveRoot. Its false isPersistent/null ID follow the 2020 pointer-based contract; GS itself calls subWorldDraw to draw only the same small nontext calibration. No manual worldDraw/context, point overrule, text or N9b qualification. A real callback is required before RGB/calibration; context database is observed, never claimed as SideDB success. The root address survives view/model removal and deletion, and diagnostic resources participate in cleanup/unload refusal. DiagnosticOnly/qualification=false and the original main failed result are preserved. No control runs for another failure cause.

Deferred dispatch is a startup-command timing diagnostic, distinct from the exhausted view-internal A/B/C/update hypotheses. Entry, idle-ready and capture snapshots are in readable dispatch-trace.jsonl and dispatch-state.json; there is no per-idle log stream, sleep, timer framework, OPEN/REGEN/display action or shared bridge/watch modification. Repeated exact entry is a no-op; eOk means queued only. Pending/queued callbacks block unload. Native terminal Evidence is created only by actual capture; failure to reach capture is dispatch/infra, never a fabricated GS result.

N9h supersedes N9g's unsupported-only provider with a finite public owned-resource catalog. Both fresh diagnostic arms, and the replacement generic/direct-value fault1 at the existing after-model-association point, complete all explicit owned-DB marker/style writes and the sixteen-field persistent-source verification before any catalog pin or model/view creation. This preparation order and cache readiness differ from frozen v24, so an outcome change is not attributable solely to the provider. Main and fault3/fault2 retain their original manager/ID timing.

The catalog enumerates the owned empty database's nine SymbolTable bodies and records, recursive NOD dictionary paths/values (including public dictionary subclasses), and the known owned marker/modelspace aliases. Public IDs supply asOldId keys; visited/dedup preserves aliases and prevents cycles without additional opens or arbitrary entry limits. Each unique safely verified same-ownDb object has one independent successful kForRead reference and its true AcDbObject-to-AcGiDrawable pointer. Failed/unavailable entries and incomplete enumeration remain explicit; this is not a claim of coverage of every GS resource. owned-resource-catalog.json records the ready catalog; final provider observations retain per-entry open/close status and actual borrowing facts.

Named get/release callbacks only lock the memory directory and record raw ID/flag/thread, public role/class/real ID, pointer and counters. Get returns the exact pinned drawable for an exact known usable key; unknown or unavailable requests stay unsupported/null. It does not decode raw IDs, derive handles, open foreign/unknown objects or infer a bNeedsValidation protocol. Release only matches a real borrowed pointer and decrements its borrow count; it never closes or deletes it. One underlying read-open reference survives all view/model use and actual model deletion, then the provider is withdrawn and each acquired reference is closed once with the actual status checked before database deletion. Failed closes retain the object reference/database/Session and block successful cleanup/unload. Borrow counts are separate from physical pin references: outstanding borrows after model deletion are reported as observedReturnIncomplete, never invented as returned and never alone treated as a failure because the SDK does not guarantee one observed release per get. Unknown-pointer release or borrow underflow remains a diagnostic protection failure; pins can only close after model deletion. Catalog pins participate in terminal/unload protection. No get means no dynamic provider verification, and no release means no release behavior was tested. All original real-callback/RGB/fixed-calibration gates and diagnosticOnly/qualification=false limits remain.

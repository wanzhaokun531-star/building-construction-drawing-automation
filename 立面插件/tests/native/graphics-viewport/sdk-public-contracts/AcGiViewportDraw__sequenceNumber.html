AcGiViewportDraw::sequenceNumber
C++
virtual Adesk::UInt32 sequenceNumber() const = 0;
Description

Returns the number of viewports deleted so far during the AutoCAD edit session for the current drawing. If this number has incremented since last checked, then some viewport has been removed.

AcRxOverrule::addOverrule Method   
C++
static Acad::ErrorStatus addOverrule(
    AcRxClass* pClass, 
    AcRxOverrule* pOverrule, 
    bool bAddAtLast = false
);
Parameters
Parameters 
Description 
pClass 
Pointer to an AcRxClass that pOverrule applies to. 
pOverrule 
Pointer to an AcRxOverrule derived object to overrule. 
bAddAtLast 
Indicates whether the {pClass, pOverrule} pair should be added at the end of overrules collection. 
Returns

Acad::Ok if the overrule is successfully added.

Description

Registers an overrule object for an AcRxClass.

Remarks

You should ensure the overule is appropriate for the target class. If the overrule cannot overrule behaviors in the target class, then the overrule will have no effect. If more than one overrule specifies bAddAtLast to be true, then their order will be determined by last in first out.

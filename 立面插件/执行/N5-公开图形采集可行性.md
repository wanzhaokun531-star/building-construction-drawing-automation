# N5：ObjectARX2020 公开图形采集可行性调查

日期：2026-11-01。性质：只读资料调查与探针设计。本轮只新增本文，没有编译、启动或控制 CAD，没有写 DWG、修改共享源码或读取天正私有实现。

**结论：存在有官方样例支持的公共调用入口，值得实施独立探针；尚未证明本机 TDbDimension2 经该入口会回调实际文字，更未证明已经取得完整字形。** `AcGiDrawable::worldDraw/viewportDraw` 不依赖天正开发 SDK 的头文件和导入库，但执行真实 TCH 绘制仍依赖宿主中实际加载的 TCH 对象实现或正式 Object Enabler。只有代理对象时不能据此读取原生尺寸文字。

第一阶段应验证“真实根的绘制回调→实际 text 字符串、位置、样式→经过字体和坐标验证的字符串范围”，而非承诺一次实现字形轮廓。单独 `extentsBox` 给字符串框，不能声称取得字形笔画。若 TCH 实际回调多段线或壳体，也只能记录真实原语；没有可靠归属证据时不能把靠近数字的线段猜成文字。

本调查不改变授权范围。未发现新的标高、轴号、图名或索引业务 setter；图形观察不能代替根业务属性的读写。

## 3. 文字能读到什么，边界怎样求

### 3.1 回调的证据级别

1. **实际 text 回调已到达**：记录原字符串、显式length/raw、位置、normal/direction、当时矩阵/traits、world或viewport阶段和父child路径。只证明绘制实现发出了这一文字请求。
2. **实际有效文字样式已取得**：对带 `AcGiTextStyle&` 重载逐项读公开getter，字体资源解析路径和SHA另记。借用引用仅在回调期间有效；不能保存对象地址或内部pImpl指针等到以后再读。
3. **字符串范围已取得并经过验证**：使用捕获的真实字符串和真实样式，`loadStyleRec(目标db)` 后，调用 `extentsBox`，记录原始状态及2D min/max，再经该文字坐标系和累计模型矩阵得到框。不能丢失负min只保留width/height，也不能把宽因子、tracking或倾斜重复乘两次。
4. **字形笔画/墨迹已取得**：只有实际绘制发来的几何具有可证明的文字归属、坐标与裁剪完整性，或者另有经查证的正式公开轮廓API并实测后才能称此项。本轮未证明该级。

短text重载只有height/character-cell width/oblique，不能擅自取图中同名STANDARD。2020 CHM指出它初始使用acad.exe内建STANDARD，而非DWG内的STANDARD；没有取得有效字体时应为 `styleIncomplete`。带样式重载也不能把根 `_TCH_DIM_T3` 记录覆盖callback自己的样式。

length=-1与正值必须分开处理，不能像打印样例一样一律 `%s`。本机text说明对正length使用“bytes”措辞，而 extentsBox说明按字符长度；2020 ACHAR/UTF16条件下必须用已知ASCII、中文、显式非零结尾slice控制样本查清实际单位，原始整数和UTF16序列都保留。未解决前不可宣称通用Unicode读取完整，也不可越界读取或静默截断。

MText换行、上下标、分数/堆叠、格式控制码可能分为多个text或几何callback。不能预定“每段尺寸恰好一次text”。先记录运行顺序与路径，再验证可见run的组合；不要把标准尺寸 `formatMeasurement` 返回的 `\\A1;400` 直接放到推定位置当实际文字。

### 3.2 extentsBox 的真实条件与限制

2020 CHM `AcGiTextStyle::extentsBox` 明确要求先 `loadStyleRec()`；ctxt=null时使用AutoCAD默认regen pipeline，在ObjectDBX中必须给有效WorldDraw。penups控制空格是否计入，raw=true时不解释%%等转义。[官方 extentsBox 交叉说明](https://help.autodesk.com/cloudhelp/2018/ENU/OARX-RefGuide/files/OREF-AcGiTextStyle__extentsBox_ACHAR___Adesk__Boolean_int_Adesk__Boolean_AcGePoint2d___AcGePoint2d___AcGiWorldDraw___const.html)。

已另读2020 CHM `AcGiTextStyle__loadStyleRec.html`：该函数加载font而非数据库style；返回int位掩码，0x01为当前font/bigfont已加载，0x02/0x04分别为font/bigfont加载失败，0x08/0x10分别为已用另一font/bigfont替代并将新文件名复制回AcGiTextStyle。故应记录返回位及调用前后实际文件名，替换不能静默算“原字体匹配”；不能机械当Acad::ErrorStatus或假定零必成功。所有度量准备只作用于自有style，不能对callback借用style做变更。

建议回调只复制公开值并记录，不在递归text回调中立即求extents，以免度量过程再次使用同一collector造成重入。求框单独阶段进行，使用独立度量上下文或宿主默认管线，并分别报告该配置是否可用；不能为了“成功”去注册全局默认AcGiContext。

normal/direction定义文字坐标轴，须验证非零、相互垂直及规范化规则；倾斜、镜像、竖写、非均匀模型变换须由标准控制样本核对，不能只用angle旋转一个宽高矩形。WorldGeometry是模型坐标的绘制；ViewportGeometry另分模型、eye与DC原语，需保存其坐标空间。缺相机/像素映射的DC文字只能记 `unmappedDeviceGeometry`。

### 3.3 一个被排除的“有头文件”入口

`inc/textengine.h:32–74` 确有 `AcGiTextEngine::create/getExtents/tessellate`，注释称shape文字可给PolylineCallback、TrueType轮廓尚未实现。但本机2020 `arxref.chm` 的两种tessellate条目及重载列表均明确 **“For internal use only.”** 因此本调查不推荐、不执行它们，不因public声明或字体为SHX就将它们算作受支持的公开字形API。

同理，不使用 `AcGiContext::getImpPtr/getConstImpPtr/wSegTaker`、受保护TrueType内部函数、`AcGiTextHook`等内部通道。当前仍无已证实的、通用完整字形轮廓提取方案。

## 4. 宿主上下文、比例、所有权与副作用

**能传自有WorldDraw不等于可以脱离真实宿主。** 官方样例运行在AutoCAD命令中。TCH可能还读取workingDatabase、当前文档、已加载字体、注释比例或内部显示缓存；本轮没有执行，不能保证SideDB+四方法Context足够，也不能反向断言一定需要可见窗口。

应分两档明确报告：

- A：真实AutoCAD2020隔离宿主中，独立目标库的root，`Context::database()`精确返回目标库，合成World上下文直接采集。Context不谎报支持TrueType/ownerDraw；遇到不支持能力或内部依赖时停止并记partial。
- B：若A需要viewport/宿主真实上下文，在自有测试文档和自有GS视图内使用转发式AcGi适配器，从由宿主调用的自有wrapper drawable收到真实WorldDraw/ViewportDraw，转发公开context/viewport查询并截取图元。wrapper只引用本次映射clone；不注册全局overrule、不拦用户实体，不把TCH私有context指针拿出来。B仍是待编译实测设计，不保证TCH接受包装后的接口对象。

两档均要记录regenType、isDragging、deviation、isolines、view/viewport ID、相机/矩阵、像素密度、裁剪、图层可见性、模型单位及实际可读的注释比例/打印状态。不把1:100、DIMSCALE、像素比例混为一个值。主体1:100与11B93块内小比例记录分别检验，不能全图乘固定比例。若TCH额外比例状态没有正式getter，明确unknown，并将结果限定在该宿主配置。

ownership要求：

- 源库只读；用 `wblockCloneObjects` 到新目标owner，核主映射、目标类名/nonproxy、database/owner，附必要资源映射。不能只复制一个裸实体后丢掉文字样式等依赖。
- 根按数据库打开规则close，数据库生命周期由探针持有；draw传进来的child drawable、字串、style、点数组、clip等均借用。只复制公开值，不close/delete它们，也不在callback结束后解引用。
- `draw(child)`须递归执行公开协议并入栈/出栈traits、矩阵、裁剪与路径；防循环和预算溢出。重复child允许不同实例路径出现，不能用“全局见过指针”去重而漏实例。
- 自有collector是普通C++所有权；真实宿主传入的draw/context/geometry绝不delete。GS创建的view/model/device按其工厂配对删除，并在销毁前移除drawables/view。不得混用delete。

风险边界：worldDraw语义是绘制，但可执行厂商代码并生成缓存，不能凭kForRead保证零副作用。每次调用前flush checkpoint，调用后核源模型公开指纹、源文件SHA、目标公开读数和异常状态；这些只保护已观察公开状态及磁盘文件，不证明未知私有内存完全不变。读回异常、borrowed所有权异常、stack不平衡、丢事件/超时均硬失败，已知不支持原语则明确partial。不要在绘制回调里改变实体、资源表、工作库或调用业务命令。若确需改变workingDatabase，必须在回调外有作用域恢复并单列证据，不能沿用样例的隐式工作库。

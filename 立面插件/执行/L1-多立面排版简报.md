# L1 requirements：多立面纯平移排版核心

对应实施计划任务6的独立核心。用户允许依可用图面横排/换行，不生成图框图签，不移动未选剖面/其他图形，不缩放建筑。原生实际字形准备、CAD排版图面验收尚不具备，不能以本核心夹具通过冒称当前项目完成。

文件所有权：新增src/Layout.h/.cpp、tests/LayoutTests.cpp；A1 fix冻结后才改CoreTests.cpp、ElevationCoreTests.vcxproj和tools/build.ps1注册与输入清单。不改ElevationModel/Recognition/RuleModel/AnnotationRules/MaterialRules、WriteContracts或任意SDK/原生文件。不启动CAD，不派子代理。报告执行/L1-多立面排版报告.md。

采用已有Point2/Bounds2/Result/EntityKey。WriteContracts.h只读，其LayoutPlan为单view。定义纯值ViewEnvelope（viewIdentity、源target keys、实际各类占位、完整性及来源证据）、LayoutRequest（明确可用区域、固定占位、间距、确定顺序/可重排选项和搜索预算）、LayoutArrangement（各view唯一平移+相应单view LayoutPlan、真实合并占位、比例/完整性依据）。函数Result<LayoutArrangement> arrange(...)。提交集成由后续任务核对，本任务不伪造CommitReceipt。

每view的建筑、文字字形、符号、尺寸字形及基线、材料表等可见占位整体一起平移。缺实际字形/字体一致性、占位未完整或来源为空时阻止正式可提交结果，不能把根bounds或替代字体当精确证据。测试用明确标记为synthetic_verified的占位，报告说明不是实际TCH字形。不同视图之间和固定对象之间按合并可见占位及明确净距避让；每幅只一平移，无缩放旋转。

内部标注冲突单独提供可测试检查：依据调用者明确给定的需避让对象对检测（不能把所有建筑几何互交判错）。确实检查尺寸字形和基线，即使它们落在尺寸根bounds外，也须发现与标注盒碰撞。固定剖面只读作为障碍，永远不出现在translations中。重复viewIdentity/key、跨数据库/版本混杂、非有限/颠倒bounds、负间距/比例、派生溢出和不一致实际字形证据均拒绝；不默默忽略。

采用确定性排布；允许回溯搜索候选而非只贪心。算法有明确支持范围和搜索预算；预算耗尽返回LAYOUT_SEARCH_LIMIT，不冒称数学不可排。已证明不能容纳或本算法完整搜索的合法布局族无解才NO_LAYOUT_SPACE。失败绝不缩放建筑。有限数值运算校核，不用坐标吸附修正建筑。

纸面字高换算独立函数或沿用规则：测试标准3.5纸面mm在1:100模型mm=350、1:50=175；实际角色参数来自参考，不将3.5设为生产统一默认。单位非mm时按mmPerInputUnit转换，建筑坐标不改。所选比例/字体/字形证据不同则不得复用旧Envelope。

先建立真实RED→GREEN，至少覆盖：RowsDependOnAvailableArea（2个200宽，20间隔，宽420一行/250两行）；NoFitDoesNotScaleArchitecture；ProtectedSectionIsFixedObstacle；CollisionIncludesDimensionGlyphAndBaseline；PaperSizeTracksSelectedScale；IncompleteGlyphEvidenceBlocksLayout；MalformedOrOverflowingGeometryRejected；SearchLimitIsNotNoSpace；多个view同key/身份重复拒绝；一次平移后对所有占位及target keys复读验证。保持既有全部测试，build.ps1 CoreTests/full与相关named用例均通过；封存RED/GREEN源码/日志/receipt，0warnings/errors，不复跑无关CAD。

实现结束提交短合同：状态、文件、真实RED/GREEN命令输出及路径、限制和复核差异包；由独立review-agent做一次任务复核，发现后原作者修复并仅复核fix diff。

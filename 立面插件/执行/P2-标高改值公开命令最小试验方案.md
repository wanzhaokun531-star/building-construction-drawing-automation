## 结论与建议

已安装官方资料确认 `TChangeValElev` 对应“标高改值”，快捷命令为 `BGGZ`；业务含义是给标高增加或减少指定差值。官方记录的交互流程是**先设置业务对话框参数，再到命令行选择标高对象，回车完成选择**。

**本轮没有找到公开文档支持从 ObjectARX C++ 命令栈直接传入增加/减少模式和数值，也没有找到无对话框入口或参数协议。** Autodesk 的命令栈 API 只证明能投递命令输入，不能替天正命令补出数值参数或承诺选择集兼容性。因此资料不支持目前要求的“无业务面板操作、固定位置 `2.800 → 2.923`”完整改值路线。官方文档描述了对话框流程，不足以证明所有未记录的运行条件下一定弹窗；无对话框变体是否存在仍未知。

建议保持当前限制，**不据此申请可以实现任意标高赋值的广泛授权**。若 root 认为有必要核对本机入口，最多提出下文的单次入口观察例外，告知用户其预计可能停在已被文档记录的对话框，不能承诺得到 `2.923`。没有用户明确授权，不得启动或执行。若用户目标是直接实现改值而非入口调查，当前证据不足，建议先取得正式无界面命令协议或受支持 setter；本轮不联系厂商。

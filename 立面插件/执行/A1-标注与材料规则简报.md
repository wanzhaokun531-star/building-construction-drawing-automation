## 语义和制图标准分开

FeatureModel可增加显式的ConfirmedGeometry/semanticFeatures，不把R1的unresolvedGeometry候选偷偷升级。输入角色包括主体轮廓、楼层基准、洞口、檐口、屋脊、局部线脚和材料区域，含实际几何/测点、源EntityKey、viewIdentity、确认来源；没有确认、非有限或所需几何不足时输出定位诊断。R1现有Feature列表及分析JSON行为保持。

RuleModel内定义ReferenceStandard、ReferenceFamily、AnnotationPlan/MaterialPlan及所需纯值。ReferenceStandard含真实参考SHA、按角色核准的纸面参数/布局变体/能力字段。主体字高参考纸面2.975mm、字宽0.7058823529411765；字高等不要照原表3.5盲套。当前样本800与831.877151438模型道距在1:100分别为8与8.31877151438纸面mm，保留两个显式family，不按建筑大小猜选。11B93的&&25是另一个小号块内变体，不与831.877道距混淆。

每幅或语义输入必须明确选择已核准family；缺失/不明要REFERENCE_FAMILY_REQUIRED，不自动统一道距。默认比例1:100可配置，纸面参数乘比例分母并按本项目mmPerInputUnit换算，建筑点不缩放。原生字段setter/字形能力未通过的状态原样保留；纯计划有效不等于Native PreparedBatch已可提交。

## 标注规则接口

`Result<AnnotationPlan> planAnnotations(const FeatureModel&, const ReferenceStandard&, const ProjectConfig&)`。

按已确认语义计算：主体水平总体、竖向总体/分层、真实平面轴位链（缺计划不造）、洞口宽高及必要定位、檐口/屋脊/局部构件的尺寸与标高。链记录源点和方向、真实双精度测值、分段及显示格式，不能靠改显示文字掩盖测点错误。重复同位站点去重、严格递增、无零段；不能把非整百几何吸附为整数。显示精度按参考字段，当前主尺寸整数显示但原测值保持。

零点由确认的实际datum点、heightDirection和标高值计算，不直接用文字墨迹坐标。用户确认的一层+0规则须与实际datum关联，缺点就列DATUM_REQUIRED；测试中给明确点及来源。单位从确认配置校核，仍不把INSUNITS0默认为mm。标高米值=(实际投影高度差mm/1000)+基准米值，显示三位小数及正负零表达。

总体/洞口的几何输入已按角色确认。不能对整个建筑AABB的任意角点假称原始构件点，源几何点和必要投影点分列。必要内容缺资料或歧义时保留诊断，不能静默漏标而canCommit。

至少以下新增真实RED→GREEN用例：

- ProjectLevelsDoNotUseReferenceNumbers：实际0/3000/6000、屋脊7500→0.000/3.000/6.000/7.500，不出现参考3.900、7.400、14.260。
- OpeningDimensionsUseActualEdges：洞口(1200,900)—(2400,2400)得到宽1200、高1500及真实定位来源；未确认矩形拒绝。
- TranslationDoesNotChangeMeasurements：全语义几何及datum平移(100000,-50000)，测值/标高不变。
- NonRoundCoordinatesArePreserved：实测非整值及原坐标逐值保持，显示整数另存；不得四舍五入源几何。
- DuplicateStationsNeverCreateZeroSegments：同位点与重复节点不会产生零段，仍可追溯所有源；不同合法非整点不任意合并。
- DimensionFamilyKeepsItsVerifiedSpacing：两个明确family各自道数及间距保持，未选family不能猜选；改1:50纸面大小不变、建筑坐标不变。
- MissingDatumOrSemanticRoleBlocksAnnotation：缺datum/确认/单位及inf/NaN派生值有定位诊断，不提交伪计划。

## 材料规则接口

`Result<MaterialPlan> planMaterials(const FeatureModel&, const ReferenceStandard&, const ProjectConfig&)`。

默认配置名称为深灰色仿石漆、米白色仿石漆、深灰色双波陶瓷瓦，允许项目覆盖编号/名称/表达。Hatch、普通线图、玻璃块等表达角色分开保留，源原型ID/方向/比例必须可追溯，不只靠图案名或材质名。没有材料区域就MATERIAL_REGION_REQUIRED，不从参考复制绝对区域。

先支持经确认的简单闭合外环和内部不相交孔洞；校核有限坐标、非零面积、自交/相交、孔在外环内且不封洞。不能正确处理的开放、多解、相交或触边拓扑明确诊断，不猜补。计算面积只作规则验证，不宣称已经生成真实Hatch。避免数值溢出/NaN；普通文本缺构造做法或详图号时不输出参考项目专有内容。

表格/图例与明确视图ID或共享表ID关联，不按最近标题或Y唯一决定。重复区域/空关联要诊断。

新增用例：

- WallMaterialExcludesWindowHole：外环(0,0)—(10000,6000)，洞口(1200,900)—(2400,2400)，面积58200000mm²，孔内点无材料。
- InvalidOpenRegionNeedsCorrection：不闭合、自交、外部孔/交叠孔、未知单位及非有限派生拒绝；不自动封口。
- MissingConstructionAndDetailIdBlocksItsAnnotation：缺目标构造/详图编号，不输出成品造型/雕塑/D08等参考专有文本；有真实数据才输出。
- MaterialDefaultsAreProjectOverridable：三默认名可改，不把Hatch/线图/玻璃块混成一种表达，视图关联明确。

所有测试用真实纯值输入，不mock SDK；先可编译空规则看到行为RED，再实现。用--all跑完整核心套件、逐名覆盖新增。冻结源码/fixture及日志/收据；报告尚未验证的Native生成/真实项目区域/字形/轴网。不得创建实际交付目录或发布ARX。

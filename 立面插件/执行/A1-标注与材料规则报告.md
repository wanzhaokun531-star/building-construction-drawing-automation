## 实现的规则

两入口为 `planAnnotations(const FeatureModel&, const ReferenceStandard&, const ProjectConfig&)` 和 `planMaterials(...)`。只消费显式semanticFeatures，绝不把R1候选或已有Feature列表升级为已确认输入。每个构件保留viewIdentity、实体来源、确认来源和实际几何；缺确认、缺必需角色、无效来源/视图、重复身份、非有限坐标或派生溢出均阻断。诊断保留可用的视图及EntityKey；视图级缺项没有伪造实体位置。

ReferenceStandard由调用者显式提供参考SHA256、核准来源、按角色许可的family及材料原型。它不自动创建项目标准或选择family。参考源SHA使用 `109BDCFEA4C55219793F2B6F9D8C8B619344B51A4C73E9129378C38532B2AF4D` 的纯值夹具。主体纸面文字高度默认2.975mm、宽因子0.7058823529411765；family参数须通过显式核准验证才可消费。

测试分别给出8mm和8.31877151438mm纸面道距，两者不合并，不按建筑大小猜选。道数是夹具显式提供的3道/2道，用于证明调用者指定布局被原样保留，**不是实际参考图全部排法已核准的道数结论**。11B93的&&25用独立variant表示，未核准时拒绝，不与831.877151438混淆。1:100默认比例可改1:50；纸面参数乘分母再除mmPerInputUnit，实际建筑点不缩放。未通过的原生setter/字形能力枚举原样传递，纯计划不能改变这些能力状态。

标注计划包括主体水平/竖向总体、按明确视图聚合的分层链、真实已确认平面轴位链、已确认矩形洞口宽高及水平/竖向定位、檐口/屋脊/局部构件尺寸和标高。主体总体取真实输入点的投影极值，不制造建筑AABB角点作为源点；原始点与派生投影点分列。链保留全部源点、归并来源及双精度测值。只按严格相同投影站点去重，保持全部重复来源；相近的合法非整站点不合并。显示整数另存，不修改源几何或实测值。

标高使用已确认实际datum、实际高度方向和基准米值：投影差×mmPerInputUnit/1000＋datumMeters。须同时有现有ProjectConfig中的零点规则确认及datum确认来源。显示三位小数、`±0.000` / `+3.000` / 负号；不从文字墨迹坐标取零点，也不复制参考标高。缺平面会给PLAN_REQUIRED；没有生成或假设真实项目轴位。实际一层+0仅有规则而无实际点时给DATUM_REQUIRED。

材料配置默认M1深灰色仿石漆、M2米白色仿石漆、M3深灰色双波陶瓷瓦；项目可覆盖编号、名称和核准表达原型，也可明确添加材料键。Hatch、普通线图和玻璃块分别记录表达角色、原型ID、方向、比例和核准来源，不以名称代替表达。区域保留实际外环、孔洞、来源、面积、family及视图/共享表关联。面积只作规则验证；`materialContains`排除孔内和孔边点。

支持简单闭合线段外环及严格内部、互不相交孔洞。拒绝开放、自交、零面积、非有限、外部孔、交叠孔、孔套孔、触边和溢出拓扑；不自动封口。重复区域按ID及几何校验，几何比较忽略起点、方向、显式重复首末点和冗余共线节点，实际计划几何保持原样。材料表必须明确关联本视图或唯一共享表ID。缺构造或详图号时不生成该注记并给CONSTRUCTION_DETAIL_REQUIRED，不写参考专有文本。

## Fix round 1：旋转矩形的数值分类（待限定diff复核）

复核P2属实：旧rectangle()用投影坐标精确unique，30°旋转的合法矩形出现1199.9999999999998与1200等末位差异，因此被误判为多于两条边。先在原OpeningDimensionsUseActualEdges用例中补30°覆盖，再执行真实RED；原49项注册不增删。

仅修改 `src/AnnotationRules.cpp` 和 `tests/AnnotationRulesTests.cpp`。矩形分类改用以第一个实际角点为局部原点的两轴投影；每轴将四点排序，要求低/高两组各有两个误差范围内相同的站点，并且两组可数值分辨；组合后四个角类别必须各不相同。分类误差预算取binary64的unit roundoff `u=epsilon/2`、`gamma16=16u/(1−16u)`，乘每点局部投影乘积绝对值之和。16步预算覆盖局部减法、归一化基向投影及短旋转计算的舍入余量，不是模型毫米容差，也不使用建筑尺寸或远处datum放大容差。

分类只计算标签；原源点、原投影站点、尺寸链和measuredMm的计算没有修改。回归同时校验30°合法洞口得到接近实际1200×1500的测值、原四点坐标及EntityKey逐值保持；沿局部宽方向把一角真实偏移0.000001输入单位的梯形仍给INVALID_OPENING_GEOMETRY。该偏移远大于本夹具约10⁻¹²输入单位的舍入预算；已有非整坐标保持、平移、实际方向及非矩形拒绝断言继续通过。

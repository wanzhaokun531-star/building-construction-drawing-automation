# 建筑施工图助手 0.1.3

适用于 AutoCAD 2020 x64 / R23.1，需已安装兼容的天正对象运行组件及字体。在普通 AutoCAD 中加载，无需启动天正界面。运行期不需要 Python、COM 或 Computer Use。

## 安装和运行

1. 保存图纸并关闭所有 AutoCAD。
2. 运行包内“安装程序.exe”，点击“开始安装”。安装到当前用户的 Autodesk/ApplicationPlugins/BuildingPlan2020.bundle。
3. 完整、未自定义的0.1.2会自动备份到相邻backup目录后升级；旧文件有自定义修改时拒绝覆盖。其他旧版本先自行备份并移走旧bundle，勿同时加载多版。
4. 打开已定稿的原方案，保存后输入 `BCP_BUILD`，选择新的输出文件名。两组平面会分别生成一层、二层DWG，原方案不覆盖。
5. 输入 `BCP_ISSUES` 查看清单，`BCP_CHECK` 读取输入情况，`BCP_INFO` 查看版本。

AutoCAD保持SDI=0、SECURELOAD=1。已安装天正组件目录需要位于受信任路径内；默认组件目录为C:/Tangent/TArchT20V8/SYS23x64，位置不同可编辑bundle/Contents/Win64/BuildingPlanPlugin2020.ini中的tangentDirectory。不关闭全局安全检查。

## 本版接入内容

本版以已经确认的两层定稿方案为对象，将一层v11、二层用户修改后v12的标注布置接入正式BCP_BUILD。读取原方案墙、门窗、家具等建筑对象；从项目配置中的原生天正标注原型创建施工标注，源墙体不以样张墙体替换。不是直接把样张DWG复制成成果。

- 室内门M、室内洞口DK、外立面防盗门FMD、窗LC、外推拉门LM；卧室、厨房、卫生间入口用M。编号写入各自TDbOpening并由门窗对象自身显示，不与门另套普通块/组。编号位置及尺寸避让沿用已确认布置。
- 房间按所关联的实际源墙内边围合计算；同一公卫合并显示一个面积，实体墙不计，内部隔门不另分房间。显示数值+m²，上标2采用天正排法；有名称置其下方，无名称置中部。当前净域语义和墙面关联由已确认项目配置提供，未声称已实现任意户型的房间语义识别。
- 总面积按外墙外轮廓，一层门廊上平台4600×1380半计，露台、台阶不计；二层门廊投影不计。当前应显示一层189.78m²、二层153.49m²。
- 真实整体TDbDimension2连续链；第三道及内部尺寸使用PUB_DIM。保留用户二层修改的尺寸删改、测点、字点及25号色；一层按其已确认样张配置，不照搬二层坐标。
- 真实TDbAxisLabelSet直接位于模型空间；轴线为独立AcDbLine，不套普通块和额外轴网组。单侧显隐按确认图面；二层底侧补1号轴；图名与轴圈冲突时移动图名。

## 使用范围和未决项

当前验证目标为既有两层定稿方案。原200/100墙厚案例保留既有基础生成功能；本轮样张新功能不自动扩展为所有新工程均可适用。另存但建筑未改的原方案可按实际几何识别；新的布局需重新建立规则及确认布置。请从原方案生成，不把修改后的施工图当成方案输入。

旧DK0918布置仍按“保持原侧，待调整”处理；图面局部密集处需人工确认。内部卫生间隔门的尺寸及编号继续取消。散水、明沟暂停。正式CTB/图框/固定详图库、其他构造及完整施工图模块未纳入本次完成范围。

面积在执行生成时重新计算，不是随之后手动改墙即时联动的字段。当前原生轴号是每条逻辑轴的独立集合，支持已验证的改号及侧向控制；未承诺全方向自动合并重排的全部天正命令。不要用“炸开”天正尺寸或轴号本体来编辑。

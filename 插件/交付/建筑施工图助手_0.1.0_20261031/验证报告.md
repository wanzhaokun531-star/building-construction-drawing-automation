# 建筑施工图助手0.1首版验证

本版把已有原生验证结果整合为可加载的ObjectARX C++插件。入口 `BCP_BUILD` 从打开并保存的定稿方案开始，选择新文件名，在自有副本内生成、连接尺寸、避让编号、保存重开并打开成品。用户运行不需要Python、COM或Computer Use。测试在专用隔离桌面进行。

## 已完成验证

- 从冻结方案213个模型根实际生成，未复制已有成品作为输出；按当前项目资料核对127项公开几何/文字。
- 390个生成基础根经82次获准的 `TMergeDim` 连接，得到308个成品根。24条尺寸链共106段，均为模型空间直接存在的真实 `TDbDimension2`。
- 24条链的单夹点整体移动及82处共享节点联动进行了原生SDK试移、实际读回和恢复；保存重开后节点及尺寸值核对通过。不是以普通图块或散线模拟尺寸链。
- 18个真实天正轴号载体、20个逻辑轴Group、22段轴线和24个可见端部复读核对；未恢复底3、右C或两侧H等应隐藏的轴圈。庭院内无支撑轴段按已确认规则断开。
- 27处编号包括14个M号和13个C号。13个M号自动移位；14个M号均按原侧和本洞口投影范围布置，与所有门窗图形保持80模型毫米，与其他文字、实际天正尺寸字形及基线保持60模型毫米。这两个间距为当前项目排布参数。
- 原方案磁盘SHA保持；源文档内存中的公开几何、图层等已采字段、命名字典和遮挡条框线变量保持。两个自有中间文档通过SDK正常关闭，新DWG已另行打开。
- 四个尺寸界线遮挡条在实际打开的成品副本中原生框线值及可见框线均为0；308根图面已进行内部A2 1:100渲染检查。交付不含PDF。
- 独立几何门禁逐点核对尺寸、门号和实际字形边界；“把门号移到尺寸文字上”等反例被拒绝。文件保护测试涵盖源图覆盖、已存在输出、错误扩展名、连续外尺寸分组以及最终发布时竞争同名文件。

## 当前边界

本版仅支持本项目已确认的定稿输入及其配套资料。门窗高度等尚无通用公开读取方案的字段沿用已核准项目配置，并以实际公开几何校核项目身份；不能宣称任意新建筑均可直接生成。

4处墙体用途仍列待确认。正式CTB/STB、最终线宽、固定详图库及构造参数等后续资料仍待补齐；标高坡向、剖切索引、楼梯厨卫专项和正式图框出图等后续模块未作为本首版完成项。散水与明沟继续暂停。图面局部文字和尺寸的后续精细排布、轴号容器直接天正交互编辑及完整制图标准仍保留原验收边界。

维持普通AutoCAD2020＋原生SDK路线，仅尺寸连接使用已获准的天正业务命令。未操作天正面板，不改共用CP启动登记，不操作用户CAD。测试宿主的正常QUIT仍未作为通过项；精确停止自有宿主不等于正常QUIT。

开发过程中未通过的候选和原因保留在项目证据目录，未交付。最终二进制、示例DWG和源码指纹以发布目录 `SHA256.json` 及项目 `插件/evidence/release.json` 为准。

独立复核提出1项P2：错误日志写入失败会跳过收尾。已在隔离CAD的旧实现中以不可作为目录的真实日志路径复现任务未释放，修正为日志、解锁/释放和提示各自独立防护；最终候选v92已在同一宿主中通过故障注入、任务释放、再次成功生成，以及成品复读和正常卸载。另对多文档模式增加只读前置检查，拒绝SDI非0，不自动更改用户设置。

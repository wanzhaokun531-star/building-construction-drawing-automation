# 建筑施工图助手 0.1.2

适用 AutoCAD 2020 x64（R23.1），需要本机已安装并受信任的兼容天正组件。对象处理采用 ObjectARX C++；仅尺寸合链使用已授权的 TMergeDim，不使用 COM、Computer Use 或天正面板。用户运行不需要 Python。

先保存并确认方案定稿，再执行 BCP_BUILD，选择一个新的输出文件名。原方案不覆盖。对于本次确认的《方案施工图.dwg》两幅平面，插件分别输出“所选文件名_一层.dwg”和“所选文件名_二层.dwg”，保留每层的主楼与辅楼。240厚主要内墙、120厚隔墙均设轴；门垛/局部短墙仍不独立设轴，无法确认用途的列清单。卫生间内部隔墙上的尺寸、门编号按已确认规则省略，设轴与尺寸省略分别处理。

本版修复错误信息乱码、分项提示未命名/文件不存在/未保存修改，并在 %LOCALAPPDATA%/BuildingPlan2020/Logs 写入诊断报告。BCP_CHECK 可读取已保存图纸的实际对象、墙、门窗、代理数量；BCP_INFO 查看版本；BCP_ISSUES 打开最近结果的待确认清单位置。

输入已从随包固定计数改为实际建筑校核：原案例中增加非建筑对象不会仅因总数不同而拒绝；本次两层项目从原生公开参数读取墙厚、门窗宽高，并按各层实际数量生成与核验。项目匹配依据已确认建筑对象的实际几何，支持仅保存引起的文件字节变化。本版验证范围是原案例和此次两层案例；其他项目仍需要明确项目规则及原生验证，不代表任意图纸都已支持。

安装前关闭所有CAD窗口，运行安装程序。完整且未改动的已发布0.1.1可升级，旧目录保存在同一 ApplicationPlugins 目录下的 BuildingPlan2020.bundle.backup-*。检测到自定义或不匹配旧文件时停止，不覆盖。安装完成后重启 AutoCAD，再输入 BCP_INFO 确认显示0.1.2。也可将 BuildingPlan2020.bundle 放入当前用户 %APPDATA%/Autodesk/ApplicationPlugins；已有不同版本时先完整备份，不直接覆盖正在加载的ARX。

生成的尺寸为可编辑的整体天正尺寸链；文字允许 AutoCAD 原生文字。轴号仍以真实天正对象及原生裁剪载体显示，载体内的天正交互编辑尚未完整验收。门编号优先放门扇开启侧下方；无安全空位、无开向证据或非整百尺寸编码未确认时列待确认，不能当作全部自动排布已完成。

散水与明沟继续暂停。正式图框/CTB、固定详图库、其他构造参数、楼梯厨卫专项、标高坡向剖切索引等仍待后续模块及资料；本版是基础轴网、尺寸、门窗标注模块，不是全部施工图功能最终版。只交付DWG，不附内部QA用PDF。

# 建筑施工图助手 0.1.1

ObjectARX C++ 首版，适用于本项目已确认的定稿《方案平面图》，1绘图单位=1毫米。当前项目识别资料随包提供；建筑布局或对象数量不匹配会停止，不能作为任意新项目的通用生成器。

## 环境和安装

- Windows x64、普通AutoCAD 2020的多文档模式（SDI=0），已安装与本项目兼容的天正建筑组件及现有字体。
- 将整个 `BuildingPlan2020.bundle` 文件夹复制到 AutoCAD 的 `ApplicationPlugins` 插件目录，保留内部目录结构，重新打开AutoCAD。也可从受信任位置使用 `APPLOAD` 加载 `Contents/Win64/BuildingPlanPlugin2020.arx`，资源文件夹必须相邻。
- 默认读取 `C:\Tangent\TArchT20V8\SYS23x64` 下的已安装组件。安装位置不同时，在相邻的 `BuildingPlanPlugin2020.ini` 中修改 `[product]` 下的 `tangentDirectory`。该目录需要已经是AutoCAD认可的受信任位置；插件遇到安全拦截会停止，不修改安全设置或公共启动登记。
- 用户运行不需要Python、COM或Computer Use。仅尺寸连接调用已获授权的天正 `TMergeDim` 命令，不操作天正面板。

## 使用

1. 打开定稿原方案并保存。保持原始建筑内容不变。
2. 输入 `BCP_BUILD`，为生成的施工图选择一个**尚不存在**的DWG文件名。
3. 插件打开独立工作副本，生成轴网、三道外围尺寸、已确认范围的内部尺寸和27处门窗编号，连接为可整体编辑的24条真实天正尺寸链，处理门编号避让及图层标准，保存并打开新DWG。
4. 同目录生成 `*_生成记录_*` 文件夹，包含待确认清单、校验记录和中间副本。源方案保留，已有输出文件不会被覆盖。

`BCP_INFO` 查看版本与范围；`BCP_ISSUES` 输出本次待确认清单的位置。需要再次生成时，请切回原方案并使用新的输出文件名，不要把已生成的施工图作为输入。

## 首版边界

轴号显隐、外墙侧优先、庭院无支撑轴线断开、2000/2800/3600尺寸线位、近侧圈边600间距、连续第三道、轴到外墙边、卫生间隔墙及门编号省略、重复内部尺寸省略等，沿用本图已确认规则。14处普通门和13处已确认C前缀的门窗编号参与布置。

这是按阶段推进的首个可用模块包，尚非完整施工图自动生成最终版。散水与明沟已按要求暂停；正式图框/CTB、固定详图库、其他构造参数、楼梯厨卫专项、标高坡向剖切索引等仍按后续阶段补齐。失败时停止并保留原因，不改原方案、不伪造缺失参数。

插件不会自动更新已修改的建筑方案。只有方案定稿后才进入施工图阶段。

## 0.1.1 内墙门号位置

内墙门编号优先放在门扇开启侧的下方空白处，保持原编号、字号及随洞口旋转。仅移动编号，门窗、墙体、原房间名、轴网及整体尺寸链保持。6处按新规则布置；CD96、CDA1、CDA6、CDB9、D007五处在保持现有字号和侧向时空间不足，保留原编号位置并列入待确认，D007仍有原有墙线穿过编号，需人工处理，不能视为全部避让完成。

CD89、CDBD两处未能从方案取得开启弧，暂沿用原侧，另列为侧向待确认。请在结果同目录的待确认清单中按对象句柄定位。散水功能继续暂停。示例为当前已确认定稿项目，不代表任意方案或全部施工图模块已完成。

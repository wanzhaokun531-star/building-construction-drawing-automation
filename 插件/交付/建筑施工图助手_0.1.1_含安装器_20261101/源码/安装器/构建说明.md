# 安装器构建

独立Win32 C++17程序，v141、Windows SDK 10.0.19041、Release x64、静态CRT，无ObjectARX/COM/.NET运行依赖。
将build_payload.py中的SOURCE改为包根BuildingPlan2020.bundle的绝对路径；执行该脚本生成build/Payload.h与Payload.rc，再用MSBuild构建src/BuildingPlanSetup.vcxproj。生成bin/BuildingPlanSetup.exe。
开发测试要求调整test_setup.py的SOURCE为相同bundle，EXE指向上述bin；测试只在源码tests下创建临时目录，不操作真实AppData。--test-install仅在含BCPSETUPTEST1标记的自有测试目录可用，不是面向用户的静默安装接口。

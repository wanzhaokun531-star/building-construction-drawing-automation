# 建筑施工图助手 0.1.5

适用于 AutoCAD 2020 / R23.1 x64，需安装兼容的天正对象运行组件及字体。在普通 AutoCAD 中运行；运行时不需要 Python、COM 或 Computer Use。

## 安装与使用

1. 保存图纸并关闭 AutoCAD，运行本包“安装程序.exe”。安装位置为当前用户 Autodesk/ApplicationPlugins/BuildingPlan2020.bundle。
2. 完整的 0.1.1、0.1.2、0.1.3、0.1.4 可自动备份后升级；自定义旧文件保留，不强行覆盖。安装器同时包含新装、重复安装和失败回滚处理。
3. 打开已经定稿的原方案，输入 `BCP`（原命令 `BCP_BUILD` 仍可用），选择新的输出文件名。原方案不覆盖；成果自动打开。
4. `BCP_INFO` 查看版本，`BCP_CHECK` 读取输入情况，`BCP_ISSUES` 查看待确认清单。

组件默认目录为 `C:/Tangent/TArchT20V8/SYS23x64`。若实际路径不同，修改 bundle/Contents/Win64/BuildingPlanPlugin2020.ini 中的 tangentDirectory，并在 AutoCAD 受信任路径中配置该组件目录。保持 SECURELOAD=1、SDI=0。

## 本次修复

`DBMOD=20` 不再误报未保存建筑内容。插件读取磁盘中已保存的定稿方案，包括已保存的数据库设置；单纯视图、窗口或系统变量修改不要求反复保存。未保存的实体、字段或未识别状态仍提示先 Ctrl+S，再输入 BCP。插件不会自动保存或覆盖原方案，也不会强行清零 DBMOD。

## 延续的生成能力

新增百塘村邹总三层已确认项目：读取原输入的墙、门窗和家具，按确认方案调整墙端、柱及洞口插入位置；补齐一层楼梯上方 LC0918；生成原生天正轴号、连续整体尺寸、门窗自身编号及可编辑天正房间名。三层保留在同一张 DWG 中。

- 门窗位置与尺寸使用同一套确认坐标。示例 219/581 调整为 200/600；不是将全部尺寸强制按百毫米取整。门窗宽高、墙厚保持各自规则。
- `PUB_DIM` 使用 25 号色。第三道及内部尺寸仍为可连续编辑的真实天正尺寸链；轴线独立可拉伸，不套普通块；不使用区域覆盖。
- 编号写入门窗自身。卧室、厨房、卫生间入口用 M，室内洞口 DK，外立面防盗门 FMD，窗 LC，外立面推拉门 LM。二、三层阳台 3000 宽门用 LM3024。
- 房间面积生成时按所关联的墙面净域重算。卫生间内部隔门不拆成两个功能房间；面积仅显示数值和平方米上标，有房名放其下方，无房名放房间中部。
- 百塘项目门廊上平台、二三层阳台计一半，台阶不计。确认几何对应的层总面积为 181.52、180.28、180.27m²。

原两层定稿项目继续分别输出两张 DWG，保留用户确认的尺寸删改、门窗号、原生轴号及图名避让；总面积 189.78、153.49m²。它的露台不计、二层门廊投影不计，不能套用百塘阳台折半口径。原 200/100 墙厚案例保留已有基础生成流程。

## 使用边界

本版支持上述三个已确认项目配置，未声称已实现任意新户型的房间语义、全套构造自动识别。源墙和门窗来自输入图；标注由已确认的原生资源创建，面积生成时重算，不是直接复制整张完成样张。新的布局需要适配，施工成果不应当作原方案再次输入。

面积不会在生成后随手动改墙即时联动。原两层 DK0918 保持原侧待调整；样张中未完成全量验收的密集标注仍需人工复核。原基础案例不自动获得新项目全部语义规则。

散水、明沟继续暂停；正式 CTB、图框图签、固定详图库及其他构造模块仍待补齐。图纸交付为 DWG，本包不提供内部核图 PDF。插件及安装器不修改共享 CAD 启动登记，也不包含 Autodesk SDK、天正运行组件或字体。

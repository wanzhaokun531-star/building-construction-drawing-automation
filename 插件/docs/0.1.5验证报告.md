# 0.1.5：生成入口修复与短命令

本次修复 `DBMOD=20` 被误判为未保存建筑内容的问题。DBMOD 原来只允许 0；现在允许 4（数据库变量）、8（窗口）、16（视图）的组合，仍拒绝实体、字段及未知状态位。生成始终读取磁盘中已保存的 DWG 和数据库设置，不自动保存当前图、不清零 DBMOD。

用户输入 `BCP`，选择输出文件即可生成。保留 `BCP_BUILD`；两个注册命令指向同一生成函数。安装清单加入 BCP 按命令加载入口，安装完成提示同步更新。未保存的内容提示“先 Ctrl+S，再输入 BCP”。

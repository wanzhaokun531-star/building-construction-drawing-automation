# 从源码构建

需要Visual Studio 2019的v141 C++工具集、Windows SDK 10.0.19041，以及ObjectARX 2020 Windows x64 SDK。源码中保留 `插件/src` 和 `阶段2/src` 的相对目录关系。

使用MSBuild构建 `插件/src/BuildingPlanPlugin2020.vcxproj`，配置 `Release|x64`，C++17。SDK默认路径为 `C:\Autodesk\ObjectARX_for_AutoCAD_2020_Win_64_bit`；安装位置不同时通过MSBuild属性 `ArxSdkRoot` 指定。

生成文件为 `插件/bin/BuildingPlanPlugin2020.arx`。发布包内的资源已经按项目配置封装，重新编译后替换安装包 `Contents/Win64` 中的ARX即可；保留同名INI和相邻resources文件夹。修改规则或资源后须重新验证，不能沿用原验证记录或SHA256清单。

`阶段2/src` 是本首版复用的原生生成内核。正式入口由 `插件/src/BuildingPlanPlugin2020.cpp` 中的 `BCP_PRODUCT_BUILD` 选择；开发验证命令没有在普通用户配置中注册。

ARX、DBX和天正运行组件均须与AutoCAD2020 x64兼容。本源码包不分发Autodesk SDK、天正组件或字体。


## 0.1.2 输入适配

ARX目标仍AutoCAD2020/R23.1、VS2019 v141/C++17/x64；BuildingPlanPlugin2020.vcxproj引用同级PluginPolicy/ProductDiagnostics及../../阶段2/src，交付源码需保持该目录结构。运行期不执行Python。

新增ProductInput/NativeInputProperties/ProductDynamicInput读取实际公开参数，ProjectInput分两幅平面；当前项目规则为240/120，旧200/100默认保持。普通入口与验证入口共同调用命名/磁盘路径/DBMOD检查。生成合同以实际分段和根数计算，保留对象/数值/样式/保存重开门禁。

本地打包工具依赖项目原生资源；已有资源可从交付bundle/Contents/Win64/resources取得。安装器build_payload.py默认读插件/build/input-adaptation-final-candidate/BuildingPlan2020.bundle；先准备此目录，再运行脚本生成Payload.h/.rc，用installer/src/BuildingPlanSetup.vcxproj构建。previous-version-0.1.1.json是允许自动备份升级的已发布旧版文件哈希表，运行期不读取磁盘上的旧源码或Python。

原生测试只在独立非输入桌面工作副本执行，暂存模块正常SDK卸载后精确清理。宿主精确停止不算正常QUIT。只交付DWG，内部PDF/PNG不发布。

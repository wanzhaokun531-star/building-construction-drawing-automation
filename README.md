# 建筑施工图自动化

基于 AutoCAD 2020 x64、ObjectARX C++ 和已安装天正对象运行组件的建筑施工图自动化项目。包括平面插件、规则与资源、DWG确认样张，以及尚在开发中的立面插件。

## 当前状态

- 平面插件已交付版本为 **0.1.5**，输入 `BCP` 生成，原命令 `BCP_BUILD` 保留。本版修复 DBMOD=20 误拦截；详情见 [0.1.5验证报告](插件/docs/0.1.5验证报告.md)。
- 支持原200/100、已确认两层及百塘三层项目配置，含此前接入的原生标注、编号及面积；不代表任意户型或全部施工图模块已完成。以 [AGENTS.md](AGENTS.md) 顶部最新记录为准。
- 立面插件仍为开发候选，尚未完成完整一键生成。见 [立面阶段进展](立面插件/阶段进展报告.md)。

## 开发环境

使用 Windows x64、AutoCAD 2020/R23.1、VS2019 的 v141 工具集、Windows SDK 10.0.19041 及 ObjectARX 2020 SDK。SDK和天正运行组件需要另行安装，本仓库不打包这些组件或第三方字体。

开发验证脚本使用 Python；几何脚本原使用 `numpy 2.5.4`、`shapely 2.1.2`。本次已移出本地安装的依赖目录，换机请在开发环境安装依赖，不要把虚拟环境或第三方安装目录提交仓库。

源码和数据保留原始字节及编码，避免破坏既有SHA256核对。历史记录中的盘符、SDK位置和隔离宿主路径属于原机器环境，换机需要配置实际路径。

## Codex配置

保留 `AGENTS.md`、`.superpowers/`、项目 `.codex/config.toml`、相关本地技能，以及移除会话管道和其他项目信任项后的用户配置示例。参见 [.codex/README.md](.codex/README.md)。不包含登录令牌、`auth.json`、聊天数据库或会话历史；原机器全局配置未改动。

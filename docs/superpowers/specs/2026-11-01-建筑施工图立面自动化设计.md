## 目标与适用范围

采用 ObjectARX C++，以各项目已确定的方案立面为建筑几何依据，结合对应平面图的轴网及确认后的项目参数，一键生成可编辑的建筑施工图立面。尺寸、文字、符号、图层及材料表达以用户提供的施工图参考为标准，建筑尺寸和标高取自实际项目。

插件面向今后不同项目，不能把当前两份图的对象数量、句柄、建筑坐标、层数、轴号或材料分区位置写成生产条件。当前方案中的四个立面作为首批识别对象；后续项目按实际选择的立面集合处理，不把四张或六张设为固定数量。

本阶段保留方案建筑的形状、尺寸及每幅立面内部的相对位置。自动排版可整体平移立面及其标注，不能为适应图框而拉伸、旋转或缩放建筑。模型真实尺寸与出图比例分开管理。

本设计提出的首轮输入范围为二维建筑立面：由普通直线、多段线、圆弧、圆及其二维嵌套块表达的建筑图形，以及能够通过允许的公开接口正确读取的天正对象。层数、立面数量和洞口数量从项目取得。退台、多坡屋面等在既定构件类别内的变化属于识别及必要确认任务，不能只因形状不同就退回固定案例。三维模型的投影生成、任意第三方专有对象的解码不纳入本阶段；具体对象适配仍需验证，不能把这份支持目标写成已通过清单。

## 使用过程

首次使用一个项目时，用户指定方案立面、对应平面及要处理的立面范围。插件读取图形，给出视图划分、平面轴网对应及构件识别结果，仅将缺失或存在多种解释的部分列为待确认项。

用户补充必要的项目基准、材料分区和说明参数，选择出图比例及已有图框的可用范围，保存项目配置。后续一键生成复用仍然有效的配置，重新计算实际尺寸、标高和排布；输入改变导致配置失效时，只重新确认受影响部分。

以下按用户采纳的设计及最新成果方式执行：

- 成果直接生成到当前方案 DWG 的选定立面中，保留该图其他内容；配套平面和参考图只读。
- 命令成功后当前文档保持正常待保存状态，由用户照常保存；插件不自动另存、关闭或重开当前图。用户原有未保存编辑属于必须保留的命令开始状态。
- 无可用图框时，由用户指定排版范围；不创建新图框或图签。
- 当前比例下排不下时，提示调整范围、分组或由用户改比例；不擅自改变比例或建筑几何。
- 每次生成仅处理当前确认的立面目标，不全图清理历史结果。再次生成先核对已有标注的来源和人工改动，避免重复或误删；方案变更后的连续自动同步不纳入本阶段。
- 输入单位取可信的图中定义或首次项目配置。当前两份图 INSUNITS 均为0，需在项目配置中确认单位；方案文字中的 mm 仅作为建议毫米的依据，不替代单位确认。

### 已有标注和材料图形的处理

为落实制图标准统一且保持建筑几何的要求，读取时区分建筑几何、已有标注、材料表达和其他图纸内容。仅对选定立面中已确认归属的尺寸、楼层文字、图名及引注，先保留其有效项目数据和对应目标，再按参考标准复用、改制或替换为成果标注；同一项不与新生成标注重复。不能仅因它是原有文字就原样留下，也不能按实体类型或图层批量删除所有文字和尺寸。共用说明、材料表或归属不明确的对象，不因位于选区附近就自动纳入改制。

当前样本的“测试正立面”等源标题及“一层平面图 +0 mm”等楼层文字属于识别和数据来源，成果使用核准的立面图名及标高表达，不同时保留测试标题和重复楼层标签。不能明确对应构件或基准的原标注列为待确认项。

已有填充和材料图形先确认其角色及区域。属于本次选定立面的材料表达按确认后的项目材料及参考标准处理；构成门窗、轮廓或装饰构件的线仍受建筑几何保护，不能因其外观类似填充就删改。以上处理发生在当前文档的明确目标内，未选中的对象保持不变。

### 当前文档的修改边界

修改前记录本次目标、目标以外内容及它们实际使用的资源。正式写入只修改明确允许的对象及本次新增的资源和项目记录；其他图形不能因共享图层、样式、线型、块定义或绘图设置而发生显示变化。

失败或取消时，恢复到本次命令开始前的文档状态，包括用户此前未保存的编辑。不能通过重新加载磁盘文件恢复，也不能关闭当前图丢弃编辑。成功生成应形成可整体撤销的操作组；具体天正调用能否纳入该恢复和撤销边界，须在能力验证中证明。

## 自动识别与项目关联

视图划分结合空间分组、图名、楼层标记和构件几何，不能只按最近文字或某个坐标阈值切图。当前四个立面与两张剖面同处一图，首次应明确纳入的四个立面及其建筑范围。剖面和无关对象留在同一 DWG 内、保持不变，不参与本次立面生成。

构件识别同时使用线段连接、重复关系、轮廓、层高及配套平面信息。矩形不自动等于窗洞，水平线不自动等于楼层或檐口。普通线图无法独立说明开启方向、完成面性质或构件做法时，保留候选并提出具体缺项。

每幅立面建立独立局部基准，记录其对应建筑、观察方向、横向轴映射及竖向标高基准。平面轴号的顺序可能因观察方向反向；必须核对轴号、轴间距离和构件投影关系，不能把参考的1至10或A至K直接套给新项目。存在主辅楼或多个建筑时，关联按建筑分别建立，不只取最大图形分量。

源图中的块、镜像和旋转等变换必须转换到明确的计算坐标系。设计目标是常规二维立面输入；遇到不能可靠转换为立面测量几何的倾斜或非共面对象，应列出具体对象和原因，不能静默丢弃高度或作平面投影后宣称已识别。

## 尺寸与标高生成

### 尺寸类别和取点

| 类别 | 测点来源 | 布置原则 |
|---|---|---|
| 水平总体和轴间 | 实际建筑外边及映射后的轴位 | 按参考同类立面组织轴间与总尺寸，轴号顺序随观察方向 |
| 竖向总体和楼层 | 已确认室内外基准、各层基准及建筑顶部点 | 区分分层、分段和总高度，采用对应原型的道数与层级 |
| 门窗洞口 | 已确认的洞口边界、窗台和洞顶 | 标洞口宽高及必要定位，不能把框线或装饰边误作洞口 |
| 檐口和屋脊 | 真实屋面与檐口控制点 | 标高和尺寸对应具体几何点，坡面和装饰边分别识别 |
| 装饰线脚等局部构件 | 已确认构件边界及定位基准 | 在所需区域补细部尺寸，避免将所有碎线转成尺寸段 |

连续尺寸按实际相连测点建立整链，公共节点需要保持整体对象的编辑行为。文字位置避让不得改变测点、数值或对象关联；不得用改写显示文字掩盖实际测量不一致。建筑中真实存在的非整百值保留其测量依据，显示精度按核准的参考规则处理。

“细部自动补齐”不等于对所有线段逐条标注。实现者需从参考中归纳各类必要尺寸及冗余省略规则，并在样本上核对；无法明确其构件意义的碎线进入待确认项，不靠随意长度阈值决定是否标注。

### 标高基准

各立面以已确认的项目零点和楼层基准计算标高。给定某基准的实际几何高度及其标高后，其他已确认测点通过真实高度差换算；标高单位和小数格式按参考标准输出。

楼层名称、几何高度和标高文字冲突时列出冲突对象及两种值，由用户确定采用的基准。参考图中的3.900、7.400、11.000或14.260属于参考建筑数值，不是新项目默认层高；当前方案中的 +3000 mm 也不成为以后所有项目的默认值。

### 参考的尺寸组织需要按类别核准

当前读取表明，参考的64个尺寸对象均为模型空间直接 TDbDimension2，既有多段链，也有单段及图形内部局部尺寸。以10至1立面为分析样例，左右各有三道竖向尺寸，同侧相邻线位间隔800；底部轴间和总长尺寸之间也为800。D至L短立面则读取到两道竖向尺寸，同侧间隔约831.877。

这些是样本几何事实，尚未证明不同间距的设计原因。不能立即归纳成所有立面固定三道、所有道距统一800或统一831.877。实现前需结合实际对象比例和图面，核准尺寸类别、纸面间距及对应适用条件。

样本 AC83 的公开展开返回6个 AcDbAlignedDimension 子对象，但现有读取器未读到这些子尺寸的实际显示文字和全部覆盖参数。夹点数量和公开终参数的统计不能代替逐段数值与显示的核准。

## 材料与文字说明

默认材料配置包含参考中的深灰色仿石漆、米白色仿石漆及深灰色双波陶瓷瓦。图例、材料编号、文字和填充分别记录，允许项目调整。首次选定的材料区域需确认闭合边界及洞口扣除关系，保存后在输入变化时核对其适用性。

材料表达不局限于 Hatch。参考中既有填充对象，也有大量用于材料表达的直线及玻璃等块内容；应按核准的同类原型保持图案方向、疏密、颜色、边界和显示顺序，不能只复制材料名称或 Hatch 图案名。

材料说明、门窗开启说明及装饰引注采用参考格式，项目内容从确认后的配置取得。成品发泡陶瓷造型、壁画、玻璃栏板或雕塑等文字仅在项目确有对应构件和做法时使用。缺失做法、开启方向、材料选择或详图号先列为缺项，不把参考项目的专有说明当成普遍事实。

材料表是立面内容的一部分，可以与多个立面共用排版区域。表、图例、引注和立面建立明确关联，不能只按最近图名或Y坐标决定归属。

详图索引只指向已确认存在的项目详图，本阶段不自动编制对应详图图纸。

## 制图一致性与原生对象

“与参考完全一致”按同类对象核对，至少包含下列内容；各项目数值、实际构件数量及布局变化不要求复制参考建筑。

| 对象类别 | 需核对的内容 |
|---|---|
| 图层和实体属性 | 标准层名、颜色来源、线型、线宽、透明度、可见性及实体覆盖 |
| 独立文字 | 实际字体及大字体、字高、宽度、倾斜、旋转、对齐、内容和位置规则 |
| 尺寸及整链 | 原生对象类型、测点、链分段、实际显示值、字形、尺寸线、界线、箭头、间距及覆盖 |
| 标高和轴号 | 对应原生复合对象、符号方向、字形、编号、基准、纸面尺寸及整体编辑行为 |
| 图名和比例 | 参考同类图名形式、轴号区间或项目名称、比例文字及位置关系 |
| 引线和索引 | 引注目标、指向位置、符号大小、线型、项目文字和详图编号 |
| 材料表达 | 填充或线图原型、比例、方向、颜色、边界、洞口及遮挡关系 |

沿用项目已确认的对象要求：尺寸、标高、轴号及索引等复合标注保留对应天正类型和整体编辑能力；独立文字可使用 AutoCAD Text 或 MText，前提是样式、位置和图面效果满足参考标准。不能以普通块包装或图形炸开代替所需整体对象。

本次目标采用参考标准的图层及实际样式定义，不把开发用前缀当成交付图层。克隆资源时核对同名样式的实际定义及实体的最终引用；不能仅因名称相同就认定字体或尺寸外观相同。对建筑几何的颜色、图层和线型标准化只作用于本次目标，几何保护核对仍单独执行。

同名资源定义不同时，不能直接覆盖当前图的共享定义并影响未选内容。可使用不改变规定交付层名的依赖隔离和本次目标重绑；若无法同时满足参考标准和其他内容保持不变，列出具体冲突供配置解决，不擅自改名或替换。当前图 INSUNITS、LTSCALE、尺寸默认样式及框线显示等全局设置也不能被套用参考设置而连带改变其他图形。

参考图名均标1:100，但其中存在不同后缀的尺寸样式及不同实际字高。纸面大小需由对象类别、实际参数和比例共同核准，不能直接用样式名称后缀推断。字体文件路径可找到也不等于字形已实际显示正确。

## 避让与自动排版

尺寸、标高、文字、轴号、索引和材料表共同参与避让。既检查文字之间，也检查其与建筑轮廓、门窗开启图形、尺寸文字和基线、引线及材料表的关系。空间不足时优先调整标注线位、引注方向和图间距，不移动建筑构件或改变真实测点。

每幅选定立面连同其尺寸、标高、轴号、图名和引注构成一个排版单元。以完整有效可见范围和需要的图间净距安排单元；本次明确纳入的共用材料表单独占用区域。一行或多行根据所选可用宽高和比例计算，不把参考六个图名的绝对坐标复制到新项目。未选立面、剖面、其他图形和已有说明均作为固定占位参与排版检查，不能为腾位置而移动它们。

已有图框只提供边界。其图签、说明栏等非可用区域由识别或用户指定扣除，不能把外框整个矩形视为可用。无图框时使用用户指定范围；插件自身不新增图框、图签或图签文字。

每个视图只应用一次整体平移。平移后重新核对建筑相对几何、标注测点和完整占用范围，避免将标注遗漏在旧位置或将建筑重复位移。

## 原生接口与实现边界

目标沿用本项目的 AutoCAD 2020 R23.1 x64、ObjectARX 2020及既有 v141 工具链。运行期业务使用 ObjectARX C++，不引入 COM、Computer Use、天正业务面板或私有序列化字段写入。既有 TMergeDim 尺寸连接命令例外只用于获准的连接用途，不扩展到其他天正业务命令。

优先按角色提取并克隆已核准的参考原型，再通过允许的公开接口调整当次项目字段。尺寸、标高、轴号、图名和索引各自需要证明可修改字段及保存重开后的实际结果；能读取某类型或已有平面能力通过，不等于本立面模块已具有任意节点数和格式的写入能力。

立面模块独立形成版本和验证记录，与平面插件正式包及资源隔离。可复用经过核对的通用读取、克隆和宿主基础设施，但不能改变平面插件的已发布行为、固定案例合同或当前发布指针。最终产品是否合包属于后续交付安排，不影响本设计的功能范围。

以下事项不要求用户替实现者判断 SDK 能力，也不以用户同意设计代替验证：

3. 对当前普通线图验证四立面识别、两剖面排除、构件及轴网关联；跨项目验证包含不同视图数量、楼层、洞口数量、观察方向及构件布置。
4. 逐项核对建筑几何保护、真实测量值、标高基准、图层和样式。对象数量、编译成功或当前样本通过均不能单独证明跨项目可用。
5. 在隔离宿主的可写测试副本中验证当前文档内生成、成功整体撤销、错误或取消恢复，以及保留内容的几何和实际显示不变。保存重开检查使用测试副本，不能把验证用保存行为变成生产命令自动另存 DWG。涉及打印的一致性还需核对字体、线型、线宽及实际出图条件。

某类能力未通过时，保留具体对象、错误和未完成项，不将它静默换成外观相似但不满足要求的对象，不宣称一键完整生成成功。

## 验收条件

| 验收面向 | 完成条件 |
|---|---|
| 需求范围 | 当前文档内所选立面均处理；剖面和其他内容仍在同图且保持不变，不新增图框图签 |
| 输入关联 | 建筑、视图方向、轴号顺序、单位、楼层与零点可追溯到当次输入或确认配置 |
| 建筑保持 | 扣除排版平移和已确认单位换算后，建筑构件形状、尺寸及内部相对位置保持 |
| 标注正确 | 必要总体与细部标注覆盖实际构件，测点、实际值、显示格式和标高一致 |
| 参考匹配 | 按类别核对实际字体、字形、纸面大小、图层、实体覆盖、符号、线型线宽及材料表达 |
| 可编辑性 | 复合标注保留所需原生类型和整链或符号编辑行为，保存重开保持 |
| 排版与避让 | 所选立面和纳入的共用内容落在可用区域内，与保留图形及彼此的完整占用范围无新增冲突 |
| 多项目适用 | 至少使用另外的真实项目验证，不能用当前741根输入及参考对象数量替代通用识别 |
| 缺项和失败 | 缺项可定位、可补充；失败恢复到命令开始状态，保留此前未保存编辑，不把缺少内容的成果标记为完整成功 |
| 保存与撤销 | 不强制另存、不自动关闭或重开当前图；正常生成由用户保存，可整体撤销；配套平面、参考及冻结测试源保持只读 |

验收不以固定截图坐标作为跨项目标准。参考纸面参数、真实测点、原生对象行为以及实际图面共同构成一致性依据。

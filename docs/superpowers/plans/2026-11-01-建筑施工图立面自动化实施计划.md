# 建筑施工图立面自动化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 使用 ObjectARX C++，结合项目实际立面、配套平面及首次确认配置，在当前方案 DWG 内生成符合参考标准的施工图立面，保留该图其他内容。

**Architecture:** 采用用户选择的现有画法自动识别路线，将源几何、项目语义和参考原生资源分开。读取及计算不写当前文档，完成缺项确认、原型准备和排布后，在明确的目标及恢复边界内写入当前文档。复杂标注的公开写入能力先验证，不能以普通对象替代未通过的天正类别。

**Tech Stack:** AutoCAD 2020 R23.1 x64、ObjectARX 2020、C++17、v141、Windows SDK 10.0.19041.0；测试辅助使用 PowerShell 和项目既有隔离宿主基础设施，用户运行不依赖 Python 或 COM。

**Spec:** [建筑施工图立面自动化设计说明](../specs/2026-11-01-建筑施工图立面自动化设计.md)。执行者必须先读设计；本计划仅为后续工作安排，当前不创建下列代码文件、不运行实现或写入试验。

**分阶段安排：** [分阶段方案](2026-11-01-建筑施工图立面自动化分阶段方案.md)规定八个大阶段、交付物及验收条件；本文规定具体文件、接口和测试。任务1的只读标准采集归第一阶段，原生修改探针与任务2归第二阶段，任务3至8分别对应第三至第八阶段，不把整个任务1的写入工作提前到参考初读阶段。

## Global Constraints

- 目标沿用本项目的 AutoCAD 2020 R23.1 x64、ObjectARX 2020及既有 v141 工具链。
- 运行期业务使用 ObjectARX C++，不引入 COM、Computer Use、天正业务面板或私有序列化字段写入。
- 既有 TMergeDim 尺寸连接命令例外只用于获准的连接用途，不扩展到其他天正业务命令。
- 成果直接生成到当前方案 DWG 的选定立面中，保留该图其他内容；配套平面和参考图只读。
- 本立面生产模式以用户最新确认的 R16、R17 为准，不移植旧平面插件另存成果文件的合同；冻结测试源的保护边界保持。
- 命令成功后当前文档保持正常待保存状态，由用户照常保存；插件不自动另存、关闭或重开当前图。
- 失败或取消时，恢复到本次命令开始前的文档状态，包括用户此前未保存的编辑。
- 成功生成应形成可整体撤销的操作组；具体天正调用能否纳入该恢复和撤销边界，须在能力验证中证明。
- 当前四个立面参与生成；两张剖面留在同一 DWG 内、保持不变。
- 调整出图比例不能缩放建筑；默认1:100，纸面文字和符号标准按实际参考类别核准。
- 参考全部源数据保持只读；测试只修改自有隔离宿主中的可写副本，不操作用户 CAD、修改共用登记或复用其他任务宿主。
- 不改平面插件正式包、发布指针或已验收案例规则。没有 Git 仓库，不执行 git init，也不把未发生的提交列为完成；按任务保存源码和产物指纹。

## Review Focus

1. 当前图包含未选剖面、其他立面和用户未保存编辑：只改明确目标，失败和撤销完整恢复，不能重新读磁盘旧文件回滚。由任务2和7覆盖。
2. 目标与保留对象共用同名异定义图层、文字样式、线型、块及全局比例设置：保留对象的实际显示保持不变，冲突明确定位。由任务2和6覆盖。
3. 普通线图含嵌套块、镜像、断线和重复轮廓，另有多个建筑：保持变换正确，区分立面、剖面及建筑，歧义进入确认。由任务3覆盖。
4. 图中单位未定义、几何与楼层文字冲突、配置过期或分析后切换文档：不沿用错误测点或旧配置，写入前重新核对实际文档。由任务1、3和7覆盖。
5. 材料孔洞、密集文字、固定占位使当前比例排不下：不封住洞口，不改建筑或未选对象，不静默缩放或漏标。由任务5和6覆盖。

## 公共契约和未来命令

类型均位于 `bce` 命名空间，字段和名称在任务1锁定，后续任务不得自行更名。

- `Point2`：双精度二维坐标。`EntityKey`：当前数据库身份、对象句柄及内容修订标识，不能跨图直接当 ObjectId 使用。`UnitDeclaration` 包含图中单位及可选的用户确认；`UnitScale` 给出一输入单位对应的毫米数。
- `Issue`：稳定错误码、中文说明、视图和对象来源、所缺信息；`Result<T>`：值或诊断列表，不把有阻断诊断的结果标记为可提交。
- `SceneSnapshot`：文档身份和修订、输入单位、选定目标、受保护内容、有效可见几何及实际使用的资源定义。
- `PlanSnapshot`：只读配套平面的建筑、轴位、轴号及来源；`ProjectConfig`：已确认单位、视图和轴映射、零点、材料、比例及排版范围。
- `ReferenceStandard`：按角色核准的对象类型、资源依赖、纸面参数、布局样例及能力状态；包含实际参考指纹。
- `AnalysisResult`：`FeatureModel` 和待确认诊断。`AnnotationPlan`：具有构件及测点来源的尺寸链、标高、轴号、图名和索引需求。`MaterialPlan`：材料边界、孔洞、表格和图例需求。
- `PreparedBatch`：原生适配层独占管理的临时数据库及生成对象，不含当前文档写入；提供经实际字形测量的 `ViewEnvelope`，不暴露可跨事务使用的对象指针。
- `LayoutRequest`：比例、可用区域、固定障碍和纸面间距；`LayoutPlan`：标注合法调整及各视图一次性平移，不能含建筑缩放或旋转。
- `CommitReceipt`：本次目标、修改清单、新增对象和资源、保留内容核对、提交或恢复结果；不是 DWG 保存成功回执。

未来正式命令为 `BCE_CONFIG`（首次识别和配置）、`BCE_ANALYZE`（只读检查）和 `BCE_BUILD`（同文档生成）。配置持久化使用标准字典及记录，不引入自定义建筑实体；只修改本模块拥有的字典项，写入也须纳入撤销。未保存的新建图和已有未保存编辑均不得触发旧平面入口的“先保存文件”限制。

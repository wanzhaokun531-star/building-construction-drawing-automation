# 建筑施工图立面自动化分阶段方案

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 分阶段实现 ObjectARX C++ 立面插件，在当前方案 DWG 内生成与参考制图标准一致的施工图立面，并保留该图其他内容。

**Architecture:** 采用已确认的现有画法自动识别路线，联合读取立面和平面，首次确认歧义、材料分区和缺项。先核准参考标准及原生写入能力，再逐步实现识别、标注、材料、排版和完整命令，最后通过真实跨项目验收。

**Tech Stack:** AutoCAD 2020 R23.1 x64、ObjectARX 2020、C++17、v141。运行期业务采用原生 C++，不使用 COM、Computer Use 或天正业务面板。

**Spec:** [已确认设计](../specs/2026-11-01-建筑施工图立面自动化设计.md)。具体接口、文件和测试用例见[详细实施计划](2026-11-01-建筑施工图立面自动化实施计划.md)；本方案规定大阶段、交付物和进入下一阶段的条件。

日期：2026年11月1日。原方案制定时仅完成需求确认和首轮只读检查；用户随后授权执行阶段一。阶段一采集成果见立面插件/阶段1/阶段1成果报告.md；阶段二及其后的写入/生成工作尚未开始。

续做状态说明：上句保留方案制定时点。用户后续已授权推进其他阶段，当前实际完成、失败及未完成项以[阶段进展报告](../../../立面插件/阶段进展报告.md)及执行进度为准；本方案的验收条件不因部分实现而自动通过。

## Global Constraints

- 成果直接生成到当前方案 DWG 的选定立面中，保留该图其他内容；配套平面和参考图只读。
- 命令成功后当前文档保持正常待保存状态，由用户照常保存；插件不自动另存、关闭或重开当前图。
- 保留方案建筑的形状、尺寸及每幅立面内部的相对位置；排版只允许选定立面及其标注整体平移。
- 剖面暂不生成，原有剖面和未选内容仍留在同一 DWG 中且保持不变；不生成图框、图签。
- 默认比例1:100，可按项目调整；文字、尺寸和符号保持参考标准的纸面大小。
- 默认采用参考材料、图例及填充，允许项目调整；缺少材料分区时首次点选指定。
- 尺寸、标高、轴号和索引保留所需原生复合对象及整体编辑能力；独立文字可用符合参考效果的 Text/MText。
- 失败或取消恢复到本次命令开始状态，包括用户原有未保存编辑；成功生成可整体撤销。
- 开发验证使用自有隔离宿主和测试副本，不操作用户 CAD，不修改平面插件正式包或共用登记。
- 不把当前样本的句柄、数量、层高或绝对坐标写成未来项目的固定条件。

## Review Focus

1. 参考包含多种实际尺寸组织及比例参数：阶段一逐类实测，不能只复制样式名称或统一套一个间距。
2. 同图写入会涉及共享资源和用户未保存内容：阶段二验证故障恢复及资源保护，阶段七验证完整命令的同类情况。
3. 当前方案以普通线图表达且立剖混排：阶段三验证构件归属、剖面排除、块变换及平面映射。
4. 材料区域可能未闭合、含孔洞或缺少做法：阶段五验证边界和资料来源，不能凭参考项目推测新项目内容。
5. 密集标注和既有图形可能使排版空间不足：阶段六按实际字形与固定占位核对，排不下不能缩放建筑或漏标。

## 阶段一 参考标准核准

**工作内容：** 补齐参考图尺寸的实际显示文字、测点、局部样式覆盖、字体字形、尺寸线和界线、标高轴号、图名、索引、引线及材料表达。按实际对象归纳总体、轴间、分层及局部细部尺寸的取点和组织方式，明确纸面大小及适用条件。

当前读取已发现800和约831.877等不同实际道距，尚不能认定是统一规则或直接按长短立面分类。需要结合实际对象比例和图面核准。64个天正尺寸也不能仅凭夹点数量和样式名称认定其全部显示已读取正确。

**交付物：** 参考标准清单、各类原型及依赖目录、尺寸与标高规则说明、实测差异和待核项目表。

- [x] 各类标准已通过对象目录及四张原生图面定位，原型字体声明和资源引用已记录；尺寸独立字形叶子及字体解析/正式打印限制明列待核，不冒称程序取得所有字形边界。
- [x] 同类参数的实测变体已分列；尚不能确定的通用选择条件列入差异表，不擅自统一。
- [x] 建筑数值与制图标准已分开，参考层高、轴号和构件数量不成为项目默认值。

阶段一完成的是采集、图面观察和标准目录交付，按本阶段允许未解决项明列的口径记录。完全一致的生成效果、正式打印及各项写入能力仍须后续阶段验证，不能据此标为已完成。

**对应详细任务：** 任务1的只读采集、标准归纳及资源目录部分。原生写入探针归阶段二，不能在阶段一验收中冒充已完成生成能力。

## 阶段二 原生能力及同图修改基础

**工作内容：** 在自有测试图内分别验证尺寸链、标高、轴号、图名、索引等必需原生对象的克隆、允许字段修改和读回。验证同图选区边界、同名资源冲突、失败恢复、取消及成功后的整体撤销；覆盖当前图中已有未保存编辑的情况。

**交付物：** 能力验证矩阵、可加载最小验证模块及实际对象记录。矩阵逐项列明已通过字段、未通过能力和具体原因，不能只写“插件加载成功”。

- [ ] 实际对象类型、数值、依赖和显示正确，保存测试副本后重开仍保持。
- [ ] 连续尺寸为所需整体对象，公共节点操作能联动相邻分段；不能以普通块代替。
- [ ] 中途失败和取消恢复到命令开始状态，未选图形及之前未保存编辑保持。
- [ ] 共享图层、字体、线型及全局设置不连带改变其他内容；成功操作可整体撤销。

**对应详细任务：** 任务1的原生修改能力验证，以及任务2。必需写入能力未通过时，不进入正式生成；不依赖该能力的只读识别和规则整理仍可推进。

## 阶段三 立面识别及平面关联

**工作内容：** 识别当前四个立面及门窗、屋面、檐口、屋脊、装饰构件和楼层基准，排除两张剖面的生成。结合用户指定的对应平面，核对建筑、观察方向、轴号顺序、轴位及投影关系，建立实际测点来源。

有歧义的部分首次确认；材料区域及缺少的项目事实按已同意的方式补充。不能要求用户逐线整理全部方案，也不能把任意矩形直接认作窗洞。

**交付物：** 只读识别结果、视图和构件清单、轴网映射、项目配置及可定位的缺项清单。

- [ ] 四立面识别正确；剖面、其他图形和共用说明仍在同图且保持不变。
- [ ] 对块、镜像、不同观察方向及多个建筑的关联有核对依据。
- [ ] 单位、零点、楼层和轴网来自真实输入或确认配置，冲突不静默覆盖。

**资料依赖：** 生成轴号、轴间尺寸和核准轴向映射前，需要这份方案的正确配套平面。尚未取得平面时，可以继续验证轮廓和竖向构件，但不能把轴网部分标为已完成。

**对应详细任务：** 任务3。

## 阶段四 尺寸与标高

**工作内容：** 选一个具有代表性的立面，先生成轴号、总体和轴间尺寸、楼层标高，再补齐门窗洞口、檐口、屋脊及装饰线脚等必要细部定位尺寸和标高。按已核准类别组织连续尺寸和局部标注，并生成该立面的图名及比例。

**交付物：** 在测试图内可核对的单立面标注结果，以及测点、测量值、显示格式和对象编辑检查记录。该结果是单立面模块成果，尚不代表材料、全图避让或一键插件全部完成。

- [ ] 尺寸及标高与实际构件、单位和零点一致，不借用参考建筑数值。
- [ ] 测点去重且无零段，非整百几何不被强制吸附。
- [ ] 独立读回实际对象，验证测值、显示、原生类型、链节点和编辑联动。
- [ ] 形成生成前后对照，建筑形状、尺寸和内部相对位置保持。

**对应详细任务：** 任务4。

## 阶段五 材料与说明

**工作内容：** 提供参考材料默认配置，接入首次点选材料区域和项目调整，生成对应填充或材料线图、图例、材料表、构件说明和详图索引。已有标注和材料只在明确归属本次立面的范围内复用或改制，避免重复。

**交付物：** 可复用项目材料配置、材料表达、图例及材料表、引注与索引结果和边界检查记录。

- [ ] 材料区域边界正确，门窗等孔洞正确扣除，不遮封洞口。
- [ ] 图案、方向、疏密、颜色和文字形式匹配核准的参考类别。
- [ ] 构件说明及详图号来自实际项目；缺项补齐后才生成对应内容。
- [ ] 共用表格的关联明确，未选立面的表格或其他说明不被误改。

**对应详细任务：** 任务5。

## 阶段六 避让及多立面排版

**工作内容：** 取得实际文字、尺寸字形与基线、标高、轴号、引注和表格的完整可见范围，进行标注避让。根据已有图框可用范围或指定区域选择一行或多行，将每幅立面及其标注整体排布；未选剖面、其他立面、图签和说明作为固定占位。

**交付物：** 多立面排版结果、字形及基线冲突检查、比例检查和排版范围核对。

- [ ] 建筑内部相对几何不变，只发生允许的整体平移。
- [ ] 标注之间及其与建筑、门窗开启图形、尺寸基线和固定内容无新增冲突。
- [ ] 改比例时纸面标注大小按参考类别保持，建筑不缩放。
- [ ] 空间不足时给出具体原因和可调整项，不漏标、不移动未选图形。

**对应详细任务：** 任务6。

## 阶段七 一键命令集成

**工作内容：** 将上述模块串联成首次配置、只读分析和一键生成入口。在当前方案图内完成所选立面的标注及排版，保留其他内容；配置变化时只重新确认受影响部分。

**交付物：** 可加载候选 ARX、首次配置流程、分析及一键生成命令、完整流程检查记录。

- [ ] 从普通入口完成生成，不使用仅供测试的绕过路径。
- [ ] 再次运行不会产生重复标注；用户后来编辑的内容不会因同层或旧句柄被无条件删除。
- [ ] 切换文档、输入改变、途中取消或失败不造成误写、残留或锁未释放。
- [ ] 当前文档不被自动另存、关闭或重开，成功结果由用户正常保存并可整体撤销。

**对应详细任务：** 任务7。

## 阶段八 跨项目验收与交付

**工作内容：** 当前方案走通完整流程后，使用另一份真实项目及其配套平面，验证不同层数、洞口、轴网和视图布置的适应性。检查实际图面、原生对象编辑、保存重开、资源配套和模块卸载，完成问题修正后再打包。

**交付物：** 经验证的 ARX 和 bundle、配套参考资源、使用说明、已验证范围及待处理边界明确的验证报告。

- [ ] 两个真实项目均从实际输入完成识别、配置、轴映射和完整生成。
- [ ] 不依赖首图固定句柄、数量或标注坐标；复制首图不算另一项目。
- [ ] 正式包与实际测试的源码、二进制及资源一致，原生类型、显示及保留内容核对通过。
- [ ] 测试副本保存重开通过，冻结源和用户 CAD 未被测试修改；生产命令仍不自动保存或另存。

**资料依赖：** 另一份真实项目在跨项目验收前提供。其缺失不阻塞当前案例前面的阶段，但不能据单一案例宣称跨项目验收完成。

**对应详细任务：** 任务8。

## 阶段推进与汇报

每阶段交付具体结果、核对记录、已通过项目和未完成项。关键前置条件通过后才把依赖它的下一阶段标为可验收；独立的读取、规则整理和资料准备可以并行推进，但不能因此跳过原生写入或同图恢复验证。

现有初读记录只支持样本和资源的初步理解；阶段一仍需补齐实际显示与规则。编译、加载、计数正确、能力探针、单立面结果和跨项目验收分别报告，不互相替代。

分阶段开发继续采用同一个生产核心；各阶段验证结果随对应源码和资源版本保存。已确认的规则不反复询问，新增实测差异或确实缺少的项目事实再集中确认。

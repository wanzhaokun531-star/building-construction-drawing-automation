AcEdSSGetFilter4::beginSSGetCustomKeywordCallback Method
C++
virtual void beginSSGetCustomKeywordCallback(
    const ACHAR*
);
Parameters
Parameters 
Description 
pKeyword 
Input a pointer to the application provided custom keyword which triggered the callback 
Description

AutoCAD calls this function when an application has registered a custom keyword callback handler (acedSSSetKwordCallbackPtr() or acedSSSetOtherCallbackPtr()), AutoCAD is performing a custom selection (acedSSGet() with the ":K" option) and the user has entered a custom keyword. 

 

This function is called immediately before the custom keyword handler provided by the application is called.

AcEdSSGetFilter::ssgetAddFailed
C++
virtual void ssgetAddFailed(
    int ssgetFlags, 
    int ssgetMode, 
    AcEdSelectionSetService & service, 
    const AcDbObjectIdArray& selectionSet, 
    resbuf * rbPoints
);
Parameters
Parameters 
Description 
ssgetFlags 
One or more flag settings described by the AcEdSSGetFlags enumeration
 
ssgetMode 
One of the mode settings described by the AcEdSSGetModes enumeration
 
service 
Selection set service object created to add entities to the subselection set 
selectionSet 
Array of the entities currently contained in the selection set 
rbPoints 
Linked list of zero or more pick points that were used in the attempt to create the selection set 
Description

This callback provides notification of a failed entity subselection. 

When a subselection fails, AutoCAD usually displays "0 found" or, if Auto mode is active, changes from pick mode into crossing selection window mode. This notification occurs before AutoCAD displays a message or switches mode, giving the application the opportunity to turn an invalid selection into a valid one. 

The contents of rbPoints depends on the entity selection mode passed in ssgetMode. For example, if ssgetMode is kAll, rbPoints is a null pointer. If ssgetMode is kPick, rbPoints points to a single item containing one point. If ssgetMode is kCross, kFence or KCPoly, rbPoints points to a linked list of two or more points.

AcEdSSGetFilter::endEntsel
C++
virtual void endEntsel(
    Acad::PromptStatus returnStatus, 
    const AcDbObjectId& pickedEntity, 
    const AcGePoint3d& pickedPoint, 
    AcEdSelectionSetService& service
);
Parameters
Parameters 
Description 
returnStatus 
One of the values from the PromptStatus enumeration describing the success or failure of the selection set acquisition operation 
pickedEntity 
Object ID of the entity that the user selected 
pickedPoint 
Picked point 
service 
Selection set service object created to add entities to or remove entities from the selection set 
Description

This function is called for entsel-style entity selection like the BREAK, TRIM, and FILLET commands, or LISP (entsel).  

By using the methods of the service object, AcEdSSGetFilter clients can modify the entity selection. The selected entity can either be removed (in which case AutoCAD prompts the user to select an entity again), or replaced by a different entity. 

 

Note

An entsel-style entity selection allows only one entity to be selected, so AcEdSSGetFilter clients should remove the selected entity first (by calling service.remove()) before adding a different entity (which is done by calling service.add()). 

The endEntsel notification at AcEdInputContextReactor class level is sent after the endEntsel notification at AcEdSSGetFilter class level, in order to make sure regular AcEdInputContextReactor clients see the correct entity if an AcEdSSGetFilter client replaced the selected entity.

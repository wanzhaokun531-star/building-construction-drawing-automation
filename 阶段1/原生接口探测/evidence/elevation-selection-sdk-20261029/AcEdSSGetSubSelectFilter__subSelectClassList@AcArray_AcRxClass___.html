AcEdSSGetSubSelectFilter::subSelectClassList

    AcArray<AcRxClass*>& classes
) = 0;
Parameters
Parameters 
Description 
classes 
Input list of classes associated with the filter 
Description

This method is called by the AcEdInputPointManager instance when the filter is registered. This method is used to determine which filter to call back for filtering subentities from a candidate entity being sub-selected. 

In the case of multiple filters registering themselves for the same class, the first one wins. Internal tests use isKindOf() (in other words, derivation) to determine whether a filter applies to a candidate entity. 

Returns Acad::eOk if successful.

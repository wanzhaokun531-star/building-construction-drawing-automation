AcEdSSGet Namespace
Description

This namespace contains enumerations for the AcEdSSGetFilter class.

Structs, Records, Enums
Struct, Record, Enum 
Description 
AcEdSSGetFlags 
This enumeration contains the flag settings for an entity selection process. The settings are used by methods that add entities to or remove entities from a subSelectionSet. 
AcEdSSGetModes 
This enumeration contains the mode settings for an entity selection process. The settings are used by methods that provide notification of a failed entity subselection.

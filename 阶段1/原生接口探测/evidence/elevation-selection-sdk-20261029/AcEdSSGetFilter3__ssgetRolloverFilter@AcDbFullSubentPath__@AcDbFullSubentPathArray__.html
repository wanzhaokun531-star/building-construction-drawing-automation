AcEdSSGetFilter3::ssgetRolloverFilter
C++
virtual void ssgetRolloverFilter(
    const AcDbFullSubentPath & subEntityPath, 
    AcDbFullSubentPathArray & highlightPaths
);
Parameters
Parameters 
Description 
subEntityPath 
Input AcDbFullSubentPath of the preview highlight, down to the subentity level 
highlightPaths 
Input/output AcDbFullSubentPath of what will be rollover highlighted; modify this to control the level of rollover highlighting, if desired (the default is a top-level entity) 
Description

This callback provides notification and filtering of a pending preview (rollover) highlight. 

Preview highlighting causes entities to be automatically highlighted as the cursor passes over them. Modify highlightPath to control which entity or subentity gets preview highlighted. To leave a preview highlight unmodified, make no changes to highlightPath. To prevent a preview highlight, assign highlightPath to an empty AcDbFullSubentPath. To change a preview highlight to another entity or subentity, modify highlightPath accordingly.

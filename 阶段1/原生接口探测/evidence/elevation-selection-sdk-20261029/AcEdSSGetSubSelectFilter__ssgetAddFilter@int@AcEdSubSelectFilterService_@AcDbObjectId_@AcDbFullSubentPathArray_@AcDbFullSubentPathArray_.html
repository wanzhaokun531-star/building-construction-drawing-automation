AcEdSSGetSubSelectFilter::ssgetAddFilter
C++
virtual void ssgetAddFilter(
    int ssgetFlags, 
    AcEdSubSelectFilterService& service, 
    const AcDbObjectId& object, 
    const AcDbFullSubentPathArray& selectedPaths, 
    const AcDbFullSubentPathArray& addedPaths
) = 0;
Parameters
Parameters 
Description 
ssgetFlags 
Input combination of one or more flag settings described by the AcEdSSGetFlags enumeration 
service 
Input selection set service object created to add or remove subentities to the selection set 
object 
Input ID of the object containing the sub-selections 
selectedPaths 
Input the currently selected subentities on the object 
addedPaths 
Input the subentities on the object being added to the selection set 
Description

This callback provides notification of a subentity selection on an object. 

You can use the methods of the AcEdSubSelectFilterService class to modify the contents of the existing selection set, or to modify the contents of the set of subentities being added before they are added to the selection set.

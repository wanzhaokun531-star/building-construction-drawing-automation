AcEdSSGetFilter::endSSGet
C++
virtual void endSSGet(
    Acad::PromptStatus returnStatus, 
    int ssgetFlags, 
    AcEdSelectionSetService & service, 
    const AcDbObjectIdArray& selectionSet
);
Parameters
Parameters 
Description 
returnStatus 
One of the values from the PromptStatus enumeration describing the success or failure of the selection set acquisition operation 
ssgetFlags 
One or more flag settings described by the AcEdSSGetFlags enumeration 
service 
Selection set service object created to add entities to or remove entities from the selection set 
selectionSet 
Array of entities that have been selected and can be modified 
Description

This callback provides notification of the end of an AutoCAD selection set acquisition operation. It offers to applications a final chance to add or remove entitites from the selection set using the methods of the AcEdSelectionSetService class. 

This notice is sent before the AcEdInputContextReactor::endSSGet() notification.

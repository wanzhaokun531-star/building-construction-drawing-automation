AcEdSSGetFilter4::endNEntsel Method
C++
virtual void endNEntsel(
    Acad::PromptStatus returnStatus, 
    const AcDbObjectId& pickedEntity, 
    const AcGePoint3d& pickedPoint, 
    ads_point xformres[4], 
    struct resbuf ** refstkres, 
    AcEdSelectionSetService& service
);
Parameters
Parameters 
Description 
returnStatus 
Optional prompt string that endNEntsel() displays before it pauses; if NULL , AutoCAD displays the Select objects default prompt 
pickedEntity 
Selected entity name 
pickedPoint 
Point used to select the entity 
xformres 
4 x 3 transformation matrix that enables the application to transform any point in the entity's Entity Coordinate System (ECS) into the World Coordinate System (WCS); if the selected entity entres is not a nested entity, is set to the identity matrix 
refstkres 
Linked list of result buffers containing the names of the entity's container blocks 
service 
Selection set service object created to add entities to or remove entities from the selection set 
Description

Gets the name of an entity selected by the user and the point used to select the entity. This function ignores the current OSNAP setting (no object snap) unless the user specifically requests it. It does not return the names of non-graphical objects. 

 

The list of linked buffers returned in refstkres are ordered from lowest to highest. In other words, the first name in the list is the name of the block that contains the selected entity, and the last name of the list is the name of the block that was directly inserted into the drawing. 

 

It returns xformres as a 4 x 3 transformation matrix expressed as four points, and it doesn't let the program specify the pick point.

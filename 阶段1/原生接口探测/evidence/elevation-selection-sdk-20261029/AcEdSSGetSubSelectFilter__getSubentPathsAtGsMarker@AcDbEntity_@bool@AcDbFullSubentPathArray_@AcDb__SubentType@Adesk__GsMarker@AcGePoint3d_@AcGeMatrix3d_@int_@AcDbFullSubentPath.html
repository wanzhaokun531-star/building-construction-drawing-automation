AcEdSSGetSubSelectFilter::getSubentPathsAtGsMarker Method

    AcDbEntity* pEnt,

Parameters 
Description

Input pointer to the entity being sub-selected

subentPaths 
Output address of a dynamically allocated array of one or more AcDbFullSubentPath objects generated from the GS marker and other information passed into this function 
numInserts 
Input number of object IDs for AcDbBlockReferences in entAndInsertStack 
entAndInsertStack 
Input array of object IDs of the objects that are the nested containers of the subentity 
Description

This method is called when a subentity selection is performed on an entity and the filter is registered for the entity's class. This method allows entities to return a different AcDbFullSubentPath for a given GS marker, depending on what has already been sub-selected on the entity. 

numInserts should be one less than the total number of entries in the entAndInsertStack list because the first entry is the entity itself, which is not a block reference. If the entity is directly owned by the model space or paper space block table records, then omit this argument so that its default of zero (0) will be used. 

The entAndInsertStack list is in order from the "main" entity that the subentity is a part of, to the outermost AcDbBlockReference that is in model space or paper space. If the entity itself is directly owned by model space or paper space, then omit this argument so that its default of null will be used. 

Returns Acad::eOk if successful.

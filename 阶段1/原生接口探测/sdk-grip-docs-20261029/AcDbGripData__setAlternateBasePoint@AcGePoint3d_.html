AcDbGripData::setAlternateBasePoint
C++
void setAlternateBasePoint(
    AcGePoint3d* altBasePt
);
Parameters
Parameters 
Description 
altBasePt 
Pointer to the alternate base point or null to disable this functionality 
Description

This method sets the object pointed to by altBasePt as the base point for any grip edit operations that use the grip to specify the drag basepoint. 

Memory for the alternate base point must be dynamically allocated. The application responsible for deallocating the AcDbGripData object is also responsible for deallocating the AcGePoint3d object. The AutoCAD grip mechanism deletes both objects when the grip is no longer needed.

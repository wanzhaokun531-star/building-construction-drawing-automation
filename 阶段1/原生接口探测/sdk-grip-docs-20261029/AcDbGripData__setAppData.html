AcDbGripData::setAppData
C++
void setAppData(
    void* appData
);
Parameters
Parameters 
Description 
appData 
Pointer to an application-specific data structure or other identifier defined, instantiated, and initialized by the application that contains the custom entity implementation code 
Description

This method sets appData as the pointer to the application-specific data for this AcDbGripData object.  

The application specific data is determined by the custom entity. AutoCAD does not access or modify the data. The host application uses a pointer to this data as an identifier for this grip when calling the AcDbEntity::moveGripPointsAt() function, so appData must not be null.
